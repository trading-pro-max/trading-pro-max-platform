# Purple Team Operations

## Purpose

Purple Team Operations converts safe red-team thinking into blue-team controls, tests, and repair drafts.

## Workflow

1. Receive a bounded local defensive finding.
2. Confirm the finding does not involve secrets, third-party targeting, or offensive automation.
3. Map the finding to a defensive control.
4. Draft a Codex-ready hardening task.
5. Require validation and Founder review when risk is high.

## Forbidden Scope

- No third-party targeting
- No exploit code
- No malware
- No credential theft
- No secret exposure
- No production mutation

## Output

Purple Team Operations produces defensive remediation plans, regression test ideas, and readiness summaries only.
