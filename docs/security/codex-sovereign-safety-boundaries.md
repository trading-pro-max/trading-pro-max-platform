# Codex Sovereign Safety Boundaries

Codex Sovereign Construction State is internal-only and read-only by default.

Hard safety boundaries:
- no shell execution from the web app
- no direct Codex execution from the web app
- no external account creation
- no emails
- no social publishing
- no billing activation
- no broker/feed activation
- no live execution
- no real-money routing
- no public launch activation
- no production secrets
- no secrets sent to Codex
- no raw sensitive logs stored
- no auth/security weakening
- no Founder Command exposure to normal users

Allowed surfaces:
- private Founder Command APIs
- internal docs
- deterministic server readiness snapshots
- public-safe Diagnostics readiness label only

Blocked public leakage:
- Codex Sovereign Construction State
- Task Constitution
- Task Parliament
- Jurisdiction Office
- Task Passport
- Execution Permit
- Result Tribunal
- Memory & Lessons
- Construction Queue
- Founder Command
- Presidency

If a task attempts to cross these boundaries, the correct outcome is blocked, quarantined, or Founder/security review.
