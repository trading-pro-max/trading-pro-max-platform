# Planet Safety Gate Matrix

Every construction event/task receives an autonomy level.

Levels:
- blocked
- suggest_only
- draft_only
- review_required
- founder_approval_required
- auto_draft_allowed
- auto_fix_low_risk_later

Current maximum autonomy:
- low-risk docs, test suggestions, reports, and small copy cleanup can be drafted
- UI, product copy, and Assistant behavior require review
- plan naming, VIP wording, media campaigns, partnerships, pricing, and sensitive user-facing claims require Founder approval
- activation requests remain blocked

Hard blocked:
- live execution activation
- real-money routing
- broker/feed activation
- billing activation
- public launch
- production secret changes
- social publishing
- fake users/revenue/metrics
- fake Pro/VIP/Institutional activation
- fake Islamic/Sharia certification
- guaranteed profit or win-rate claims
- uncontracted brand/company use

Founder approval cannot override Critical blocks without remediation.
