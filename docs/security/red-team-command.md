# Red Team Command

## Scope

Red Team Command exists only for safe adversarial thinking against owned local Trading Pro Max systems.

Allowed scope:

- Owned local system threat modeling
- Local route and auth review
- Abuse-case checklist creation
- Defensive finding summaries
- Codex-ready hardening task drafts

Forbidden scope:

- No third-party targeting
- No malware
- No exploit deployment
- No credential theft
- No phishing kits
- No illegal action
- No external attack automation
- No production secret changes

## Approval

Any red-team activity requires Founder approval before execution, even when the target is an owned local system. This pass creates readiness and decision logic only.

## Output

Red Team Command may produce local-only defensive findings, review plans, blocked decision records, and hardening drafts. It must not produce operational offensive instructions.
