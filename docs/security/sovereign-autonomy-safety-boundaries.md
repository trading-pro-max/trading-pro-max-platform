# Sovereign Autonomy Safety Boundaries

Sovereign Autonomy is local, read-only by default, and safe-by-construction.

Hard blocked:

- Secrets exposure or production secret handling.
- Live execution, real money, broker/feed activation, and billing activation.
- Public launch, social publishing, account creation, or external runner submission.
- Fake users, revenue, metrics, plan activation, partnerships, Swiss legal/company status, or Islamic/Sharia certification.
- Guaranteed profit, win-rate, or financial-advice claims.
- Shell command execution from the web app.
- Direct Codex execution from the web app.

Allowed:

- Readiness snapshots.
- Stateless idea classification previews.
- Manual-only task drafts.
- Validation plans.
- Result Tribunal reports.
- Safe Product Memory lessons without secrets or raw private sensitive data.
