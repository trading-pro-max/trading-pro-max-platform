# Essential Integrations Hub

The Essential Integrations Hub is the founder-governed registry for every tool and service Trading Pro Max needs across local operation, pre-launch planning, and future global activation.

It is readiness-only. It does not connect services, create accounts, send email, publish social content, activate billing, enable broker/feed connectivity, enable live execution, route real money, or store secrets.

## Core Rule

Connect only what the laptop planet needs now. Plan what is needed later. Block what is dangerous now.

## Priority Classes

- P0 local required: local runtime, Git/GitHub readiness, Codex task workflow, diagnostics, product memory, validation commands, and Founder Command readiness.
- P1 soon: email readiness, support readiness, secrets readiness, security readiness, and apps/platforms readiness.
- P2 pre-launch: staging hosting, managed database, email provider, monitoring, payment provider readiness, and public waitlist requirements.
- P3 post-launch: social publishing, advanced CRM, partnerships dashboard, ads, and affiliate/referral systems.
- Blocked now: billing activation, broker/live, real money, production secrets, automatic social publishing, and external autopilot.

## Product Truth

The hub preserves these hard truths:

- no live execution
- no real-money routing
- no broker/feed activation
- no billing activation
- no production secret handling
- no account creation automation
- no automatic external execution
- no social publishing
- no fake users, revenue, or metrics

## Surfaces

Founder Command may see full readiness detail, including Codex, GitHub, local runtime, secrets readiness, and blocked integrations.

Public Diagnostics may show only compact user-safe tooling readiness. It must not expose Founder Command, Codex task internals, secrets details, or external setup instructions that imply activation.
