# Alkon Orbit Command

Orbit Command represents events, tasks, coordination, Founder ideas, Task Passports, Codex drafts, and result status.

Orbit Command connects:
- Founder Idea Inbox
- classified events
- owner routing
- policy gates
- task queue
- Task Passports
- Codex draft previews
- Result Tribunal status

## Rules

Orbit Command is review-only. It may draft packets and classify work, but it must not run shell commands, call Codex directly, auto-submit work, connect services, publish, bill, trade live, route real money, or launch.

Blocked requests stay as blocked readiness records.
