# Engineering Guild

The Engineering Guild builds and maintains the kingdom. It is the disciplined technical organization behind the workstation, APIs, safety contracts, readiness checks, and future desktop/mobile/integration layers.

## Engineering Roles

- Platform Engineers: architecture, routing, state contracts.
- Frontend/Product Engineers: visible product, accessibility, theme, localization.
- Backend Engineers: APIs, persistence, auth, data contracts.
- AI/IQ Engineers: Brain, Companion, bounded guidance.
- Security Engineers: auth, abuse, secrets discipline, threat models.
- QA Engineers: regression, smoke, visual proof.
- Ops/Reliability Engineers: health, readiness, incidents, recovery.
- Mobile Engineers: future mobile readiness.
- Desktop Engineers: future desktop readiness and Founder private app.
- Integration Engineers: future broker/feed/billing/social connectors.
- Data/Feed Engineers: feed readiness, source labeling, freshness, fallback truth.

## Quality Rules

- no fake capability
- no weakened auth
- no secret exposure
- no production claim without validation
- no UI clutter
- tests scale with risk
- every high-risk change needs clear rollback notes
- visual changes require fresh screenshots when requested

## Reporting To Founder Command

Engineering reports:

- build status
- regression status
- route smoke status
- security blockers
- known gaps
- readiness contracts
- next recommended actions

## Self-Managed Support

The guild supplies data to Ops Tower, Guardian, Legal Counsel, and Founder Command so the kingdom can identify problems, explain blockers, and route hardening tasks without chaos.
