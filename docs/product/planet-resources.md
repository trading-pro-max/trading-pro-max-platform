# Planet Resources

Planet resources are the assets and flows the TPM Planet OS protects and uses to improve the product. They must be handled ethically and truthfully.

## Hidden / Internal Resources

- product truth
- platform data
- journal insights
- AI/IQ context
- trust reports
- algorithms
- accumulated knowledge

## Visible Resources

- UI
- chart
- academy
- community surfaces when built
- media content
- brand
- Swiss precision clock
- plan identities

## Living Resources

- active users when real
- community activity when real
- assistants/agents
- feedback flow
- journal activity
- media flow
- ministry reports

## Strategic Resources

- trust
- time
- Swiss-inspired identity
- VIP value
- Founder decisions
- sponsored clock future
- partnerships

## Resource Laws

- do not sell private user data
- do not expose secrets
- do not fake users, revenue, engagement, or metrics
- use resources ethically to improve product quality
- Guardian, Legal, Privacy, and Founder Command protect sensitive resources
## Economy Mapping Update

TPM Planet resources support ethical value only when protected by product truth:

- hidden resources create trust and product improvement without selling private user data
- visible resources create learning, confidence, and premium perception
- living resources create retention through feedback, Companion, journal, and community readiness
- strategic resources create governance and future growth through Swiss precision, Founder decisions, VIP value, and partnerships

No resource may be used to manipulate users, fake metrics, imply revenue, or claim activity that is not active.
