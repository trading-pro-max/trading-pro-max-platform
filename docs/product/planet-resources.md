# Planet Resources

Planet resources are the assets and flows the TPM Planet OS protects and uses to improve the product. They must be handled ethically and truthfully.

## Hidden / Internal Resources

- product truth
- platform data
- journal insights
- AI/IQ context
- trust reports
- algorithms
- accumulated knowledge

## Visible Resources

- UI
- chart
- academy
- community surfaces when built
- media content
- brand
- Swiss precision clock
- plan identities

## Living Resources

- active users when real
- community activity when real
- assistants/agents
- feedback flow
- journal activity
- media flow
- ministry reports

## Strategic Resources

- trust
- time
- Swiss-inspired identity
- VIP value
- Founder decisions
- sponsored clock future
- partnerships

## Resource Laws

- do not sell private user data
- do not expose secrets
- do not fake users, revenue, engagement, or metrics
- use resources ethically to improve product quality
- Guardian, Legal, Privacy, and Founder Command protect sensitive resources
