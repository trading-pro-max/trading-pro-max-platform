# TPM Dual-World Operating Civilization

Trading Pro Max operates through three separated worlds:

1. Public User World: a simple professional trading product.
2. Private Founder Command World: the owner-only command, security, build, memory, review, and readiness world.
3. Invisible Operating Layer: the internal systems that carry product truth, safety, routing, diagnostics, memory, and build intelligence.

Core law: the user sees simplicity, the founder sees control, and the invisible operating layer carries complexity.

This doctrine does not launch the product, enable production, activate billing, connect broker/feed systems, enable live execution, route real money, or publish socially.

## Private Founder Command World

Founder Command remains private/internal. It may use internal language such as Founder Command, ministries, councils, governance, local operations, construction queue, Codex task drafts, product memory internals, secrets authority, security sovereignty, treasury controls, approvals, and local universe.

Founder surfaces are not public navigation, not a user plan, not a paid feature claim, and not a normal account upgrade.

## Invisible Operating Layer

The invisible layer includes Product Truth, Plan Entitlements, TPM Assistant Context, Why Blocked, Guardian, Legal, Trust Governor, Brand Intelligence, Product Memory, Diagnostics internals, Local Day Cycle, Founder Reporting, Construction Intelligence, World Interface Readiness, and Security Sovereignty.

Normal users receive only mapped, public-safe outputs from this layer, such as:

- Live execution is not active.
- Billing is not active.
- VIP is planned.
- Safety readiness is active.
- Support channels are planned or readiness-only.

## Non-Launch Boundaries

The dual-world model preserves:

- no live execution
- no real-money routing
- no broker/feed activation
- no billing activation
- no production activation
- no social publishing
- no fake users, revenue, or metrics
- no fake Pro, VIP, or Institutional activation
- no fake Swiss legal/company status
- no fake Islamic/Sharia certification
