# Global Nervous System

## Definition

The Global Nervous System is the internal model for detecting and routing external signals without external automation. It receives no live messages in this pass; it defines how future signals will be classified safely.

## Signal Types

- Email received
- Support request
- Partner request
- Media request
- VIP interest
- Institutional interest
- Social comment
- Social DM
- Brand impersonation
- Security alert
- Legal notice
- Public complaint
- Content opportunity
- Scam attempt

## Safe Flow

1. Classify the signal.
2. Quarantine suspicious or unsafe material.
3. Draft a safe response if appropriate.
4. Route sensitive items to Guardian, Legal, Security, or Founder review.
5. Keep all external actions disabled.

## Truth

This layer does not connect to the outside world. It prepares readiness only.
