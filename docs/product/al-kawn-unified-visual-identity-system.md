# Al-Kawn Unified Visual Identity System

## Purpose

The unified visual identity system makes `/founder/universe`, `/desktop/kawn`, `/trading`, and Pro Max Center feel like they belong to the same الكون.

This is visual identity unification only. It does not start Infinity Mode, Operator Mode, native desktop shell finalization, mobile apps, public launch, billing, payments, receiving money, real money, broker execution, legal approval, FINMA approval, public الكون, or public ALKON.

The canonical token file is:

- `app/_styles/al-kawn-visual-tokens.css`

Token categories:

- cosmic black

No page should create random page-specific colors for core الكون surfaces. Page-level CSS should use the canonical tokens unless a local exception is needed for chart readability or public product constraints.

## Earth / Moon Identity Variants

`AlKawnCosmicIdentity` is the canonical wrapper for the existing Pro Max Earth/Moon identity.

Variants:

- `hero` for `/founder/universe`
- `desktop` for `/desktop/kawn`
- `tradingCompact` for `/trading`
- `center` for Pro Max Center
- `tinyChip` for compact chips

Moon orbit appears where space allows. The Swiss red precision mark remains small and visual only. Reduced-motion remains delegated to the existing Earth/Moon identity system.

No generated image dependency, external unlicensed asset, NASA claim, official Swiss symbol, or government endorsement is allowed.

## Product Truth Visual Rules

`AlKawnProductTruthStrip` is the canonical Product Truth strip style.

Core truth:

- public launch blocked
- billing inactive
- payments inactive
- receiving money inactive
- real money disabled
- broker execution disabled/not connected
- legal review pending
- Pro Max working_name_only
- ALKON private/background
- الكون private to Ahmad devices
- Product Truth enforced

Product Truth must never be hidden or demoted below visual spectacle.

## Page Usage Rules

`/founder/universe` uses the strongest command-center identity: root law, visual map, kernel, Product Truth, boundaries, and canonical Earth/Moon hero.

`/desktop/kawn` uses the same identity as a deeper desktop operating environment with chat, task, decision, report, reality, kernel, protection, and vault panels.

`/trading` uses the same identity in compact form. Chart readability and trading function remain the priority.

Pro Max Center uses the public-safe version of the identity. It may show Pro Max Earth/Moon and Product Truth, but it must not expose private الكون details as public product claims.
