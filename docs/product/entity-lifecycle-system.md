# Entity Lifecycle System

Entity lifecycle:

idea -> planned -> drafted -> built -> tested -> accepted -> monitored -> improved

Accepted entities may later become deprecated, archived, or removed, but removal requires safe migration.

Lifecycle law:
- no accepted entity without validation
- no public entity accepted with public/private leak risk
- no sensitive entity accepted without security or Founder review
- no visual entity accepted without visual proof when required
- no launch entity accepted without launch gate
- no deprecated entity removed until dependents are migrated
