# System Weather Language

System Weather maps product readiness into public-safe atmosphere language:
- ready_clear: product ready
- fallback_fog: fallback or demo state
- blocked_red_signal: blocked action
- review_clouds: review required
- maintenance_cold: planned or inactive maintenance
- degraded_dim: degraded readiness
- build_failed_storm: build or validation failure

Diagnostics may show these as compact readiness labels. Public UI must avoid
private terms, Alkon terms, command terms, or internal governance language.
