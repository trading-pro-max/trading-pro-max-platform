# Visual Acceptance Engine

The Visual Acceptance Engine is a strict rubric for reviewing the product visually.

Runtime source:

- `lib/server/visual-acceptance/types.ts`
- `lib/server/visual-acceptance/rubric.ts`

Rubric areas:

- public entry
- workstation
- chart
- execution ticket
- settings
- diagnostics
- auth/session
- feedback
- dark theme
- light theme
- Arabic RTL
- English LTR
- brand identity
- plan visual identity

Each area scores:

- hierarchy
- clarity
- premium feel
- clutter level
- consistency
- accessibility/readability
- product truth visibility

The engine returns score estimates, status, reasons, and next visual actions. It does not replace human visual acceptance, fresh screenshots, or browser verification.
