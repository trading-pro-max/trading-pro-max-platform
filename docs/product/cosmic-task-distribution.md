# Cosmic Task Distribution

Cosmic Task Distribution turns a task board into a governed operating chain.

## Units

- Cosmic Event: an idea, error, risk, feature, signal, or build request.
- Energy: why the event matters.
- Gravity Priority: how strongly Alkon pulls the event into action.
- Orbit Path: the route through the private operating universe.
- Planet/System Owner: the system accountable for the event.
- Satellite Monitor: the evidence watcher.
- Station: the operating desk for the task.
- Worker: the bounded execution role.
- Task Passport: the scoped task packet.
- Codex License: permission state for manual Codex-ready drafting.
- Result Tribunal: validation and acceptance review.
- Memory Universe: safe lesson/update storage.
- Founder Report: what Ahmad sees next.

## Rule

Each task must have a full chain before work begins. Blocked or forbidden events still receive a chain, but their worker task, Codex license, and validation remain blocked by Product Truth.
