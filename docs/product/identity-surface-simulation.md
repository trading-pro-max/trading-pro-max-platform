# Identity Surface Simulation

Identity Surface Simulation runs deterministic identity decisions across key surfaces before visual changes are accepted.

## Simulated Surfaces

- public entry dark
- public entry light
- workstation
- settings
- diagnostics
- Assistant panel
- Journal/Coach
- plan surfaces
- private command surfaces
- mobile future

## Checks

- public/internal terminology separation
- motion level
- chart distraction risk
- plan clarity
- reduced-motion behavior
- dark/light safety
- RTL readiness
- visual clutter risk
- fake activation risk

## Output

Each simulation reports the resolved Earth Mark variant, state behavior, motion intensity, plan DNA, risks, safe adjustments, and blocked items. Public API output redacts restricted terminology while internal snapshots may keep owner-only detail.
