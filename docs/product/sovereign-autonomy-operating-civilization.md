# Sovereign Autonomy Operating Civilization

The local operating civilization turns Founder input into governed construction work:

1. Founder idea intake receives observations, concerns, visual feedback, or build requests.
2. Event classification turns the idea into a deterministic event.
3. Product Truth, safety, legal, trust, secrets, and boundary gates decide whether the event is allowed, review-required, Founder-approval-required, quarantined, or blocked.
4. Owner routing assigns the event to the correct internal owner area.
5. A Task Passport and Codex License define exact scope, validation, forbidden files, and worker authority.
6. Codex task drafting produces manual-only prompts and readiness text.
7. Result Tribunal checks validation, screenshots, scope, secrets, Product Truth, and public/private separation.
8. Memory Law records safe lessons only.
9. Founder Command receives the summary and next safe action.

The system starts after local runtime as read-only readiness snapshots and stateless intake previews. It does not persist private sensitive data or execute commands.
