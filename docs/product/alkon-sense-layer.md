# Alkon Sense Layer

Sense converts raw private inputs into safe internal signals.

Inputs can include Founder ideas, visual feedback, chart annoyance, shell duplication, public UI gaps, validation results, Codex results, blocked requests, support gaps, apps gaps, environment signals, and local day signals.

Sense removes randomness. Each signal gets:
- signal type
- source
- surface
- affected world
- safe summary
- secret-free status

Sense must never store secrets or raw private sensitive data.
