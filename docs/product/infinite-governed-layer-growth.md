# Infinite Governed Layer Growth

Infinite growth means the product can keep improving its understanding and readiness without becoming uncontrolled automation.

Allowed growth:

- Gap detection.
- Weak layer detection.
- Missing dependency detection.
- Readiness documentation.
- Validation suggestions.
- Task Passport drafts.
- Codex prompt drafts for manual external use.
- Result Tribunal summaries.
- Product Memory lessons.
- Next safe layer proposals.

Sensitive growth requires Founder approval:

- Visual identity changes.
- Chart rebuilds.
- Assistant behavior changes.
- Shell architecture changes.
- Public plan wording changes.
- VIP or Institutional claims.
- Launch readiness escalation.
- Security, auth, or secrets work.

Blocked growth:

- Billing activation.
- Live execution.
- Real-money routing.
- Broker/feed activation.
- Production secret handling.
- Social publishing.
- Public launch activation.
- Fake claims.
- Alkon public exposure.
- Direct Codex or shell execution from the web app.
