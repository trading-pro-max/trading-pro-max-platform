# Entity Validation Law

Every entity must have at least one validation method.

Validation methods include:
- TypeScript
- ESLint
- build
- regression test
- smoke route
- screenshot proof
- Product Truth check
- public/private leak check
- API safety check
- visual acceptance
- Founder review
- security review
- launch gate

Public UI entities require regression and screenshot or route proof. Private Alkon entities require public leak tests. API entities require no-secrets and no-private-data tests. Launch entities require launch gates.
