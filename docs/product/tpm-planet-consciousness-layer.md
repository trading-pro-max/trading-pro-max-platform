# TPM Planet Consciousness Layer

The consciousness layer is the internal readiness loop for Trading Pro Max construction intelligence.

Loop:
observe -> understand -> classify -> route -> decide -> draft -> validate -> learn -> report.

Inputs:
- Product Truth
- Plan Entitlements
- TPM Assistant context
- Why Blocked / state explanations
- Guardian and Legal rules
- Founder Command reporting
- Visual Acceptance
- Content Factory
- AI Build Planner
- Planet hierarchy and Presidency coordination
- Diagnostics and validation results

Outputs:
- readiness snapshot
- top gaps and risks
- safe next actions
- blocked action list
- Founder approval needs
- Codex task draft candidates
- validation recommendations
- learning notes

Rules:
- readiness only
- no production action
- no uncontrolled autonomous execution
- no fake users, revenue, metrics, launch, billing, live execution, broker/feed, social publishing, or secrets
