# Alkon Mobile Command Law

Alkon mobile command is not a public mobile app. It is a private readiness path for Founder review.

Allowed readiness:

- read status
- add idea later
- review task queues
- approve/reject/request fix for low-risk items later
- view P0 signals without secrets

Blocked:

- shell execution
- direct Codex calls
- secrets exposure
- billing activation
- broker/feed activation
- live execution
- real money
- production launch
- social publishing
- public app-store claim

Mobile command must always route meaningful actions through Founder authority, Product Truth, security posture, and audit readiness.
