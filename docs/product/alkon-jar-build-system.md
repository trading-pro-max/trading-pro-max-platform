# Alkon Jar Build System

Status: active_with_notes

Jar is the intake system before execution.

Every idea, issue, rejection, bug, cleanup candidate, future world, Codex result, Local Builder result, desktop sorting issue, or Founder instruction enters the Jar before action.

Jar sequence:

Input -> classification -> priority -> Reality Trial -> exit permit -> Command Passport preview -> Ahmad decision -> build -> evidence -> memory -> Zero Truth.

No item goes straight to execution.
