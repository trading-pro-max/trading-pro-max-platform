# Market Session Atmosphere

Market-session awareness is a deterministic visual readiness layer. It reports
Asia, Europe, US, after-hours, weekend, closed, or unknown using UTC windows.

It does not imply:
- live market feed
- broker connectivity
- execution permission
- trading recommendation
- market timing advice

Workspace use is subtle and chart-safe. Public entry can show a more visible
atmosphere, but still must not suggest live trading activation.
