# Pro Max Human Value Law

Every public action must serve a real human.

Human value can be:

- clarity
- trust
- safe practice
- learning
- reduced confusion
- beginner protection
- better support
- better Workspace usefulness
- better Assistant guidance

Founder value is also valid when it improves Ahmad's ability to operate Pro Max
safely, protect Product Truth, fund responsibly, or choose the next correct
action without overload.

Targets with no human, Founder, or product value are delayed or archived.
Vanity, clutter, and theory without product impact cannot become priority.
