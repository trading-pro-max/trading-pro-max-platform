# Station Worker Operating Model

Stations assign bounded workers.

## Stations

Design, Chart, Public UX, Assistant, Plan Realm, Support, World Interface, Security, Secrets, Codex, Tribunal, Memory, Diagnostics, Founder Review.

## Workers

Logo Identity, Chart Comfort, Public Copy, Public Navigation, Apps Platforms, Support Readiness, Markets, Academy, Community, TPM Assistant, Journal Coach, Plan Realm, Security Gate, Secrets Safety, Codex Passport, Codex Prompt, Result Tribunal, Memory Lesson, Diagnostics, Alkon Report.

Each worker has allowed tasks, forbidden tasks, allowed files/surfaces, forbidden files/surfaces, required reviews, validation requirements, report target, and memory rule.

No worker may expose secrets, activate billing/live/broker/social, expose Alkon publicly, or weaken auth/security without review.
