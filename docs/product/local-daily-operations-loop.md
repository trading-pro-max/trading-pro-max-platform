# Local Daily Operations Loop

Trading Pro Max daily local operations connect product review, Product Memory, Founder Acceptance, Product Gaps, Validation Summaries, and Codex Build Decisions into one closed local loop.

This loop is local-only, paper-safe, non-launch, non-production, non-billing, non-broker/feed, non-live, non-real-money, and non-publishing.

## Loop Stages

1. Start.
2. Inspect build.
3. Inspect routes.
4. Review public entry.
5. Review workstation.
6. Review TPM Assistant.
7. Review Journal / Coach.
8. Review Settings / Diagnostics.
9. Record Founder acceptance.
10. Record product gaps.
11. Draft Codex task.
12. Validate.
13. Store summary.
14. Close day.

## Operating Rule

The loop may draft and summarize. It must not execute launch, production, billing, broker/feed activation, live execution, real-money routing, social publishing, secret storage, or surveillance.

## Daily Outputs

- Founder acceptance summary.
- Product gap summary.
- Codex task draft candidate.
- Validation summary.
- Local day report.
- Product memory daily summary.

## Codex Rule

Codex tasks are draft-only until Ahmad manually approves and runs them separately. Drafts must include scope, forbidden scope, likely files, validation commands, product truth requirements, and a final response format.

## Memory Rule

Only safe summaries may be remembered. Do not store production secrets, API keys, passwords, broker credentials, payment data, social tokens, raw private sensitive user data, raw logs, fake users, fake revenue, or fake metrics.
