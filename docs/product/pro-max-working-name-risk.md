# Pro Max Working Name Risk

Status: working_name_only

Pro Max is useful as the current public working name, but it is not cleared as a final exclusive global brand.

Risk reasons:

- generic words
- widely used naming pattern
- Dell Pro Max usage creates trademark conflict risk
- Apple iPhone Pro Max mental association risk
- weak exclusivity for a global public brand

Pro Max may remain visible publicly as a working product label. It must not be described as globally owned, trademark-cleared, exclusive, regulated, licensed, or final.
