# Procedural Earth Fallback Law

## Principle

The procedural fallback is not a temporary broken state. It is the default public Earth renderer and must look premium without relying on external assets.

## Required Qualities

The fallback must include:

- deep ocean gradient
- procedural land silhouettes
- soft cloud layers
- atmosphere rim
- terminator shadow
- radial sunlight
- polar haze
- spherical depth
- reduced-motion support
- high-contrast readability

## Forbidden Visual Drift

The fallback must not become a toy globe, generic network globe, overloaded glow mark, or chart-obscuring background. The Workspace must remain chart-first.

## Texture Absence

If no approved texture exists, the renderer must silently use procedural fallback. Public UI must not show broken image icons or internal warnings.
