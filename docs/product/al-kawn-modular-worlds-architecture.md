# Al-Kawn Modular Worlds Architecture

## Root Rule

الكون is root.

No project owns الكون. الكون owns all worlds.

## World Rules

- كل مشروع داخل الكون له مجلد كامل مستقل.
- كل المشاريع تعمل معًا عبر Al-Kawn Core.
- الربط يتم عبر Contracts واضحة وليس عبر فوضى ملفات.
- Shared logic belongs in Al-Kawn Core.
- Cross-world communication happens through contracts.
- No random imports across worlds.

## Required Contracts

- ProductTruthContract
- KernelVerdictContract
- WorldStatusContract
- ReportContract
- RightsOwnershipContract
- PrivacyBoundaryContract
- CommandExecutionContract
- UIIntegrationContract
