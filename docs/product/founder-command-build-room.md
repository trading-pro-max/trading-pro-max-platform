# Founder Command Build Room

Founder Command Build Room is the private local construction surface for Ahmad's laptop universe.

It turns Founder Command into a build-command room without turning it into uncontrolled automation.

## Purpose

The Build Room helps Ahmad:

- observe the local platform
- see product gaps
- see visual gaps
- see Local Day One readiness
- see validation status
- see product memory
- see construction queue status
- see safe next build actions
- generate Codex-ready task drafts
- decide what to build next

## Operating Loop

Observe -> Detect gaps -> Classify risk -> Suggest build tasks -> Draft Codex command -> Wait for Ahmad approval -> Codex executes separately -> Validation result is recorded -> Product memory updates.

## Current Scope

Current state:

- local laptop universe only
- private Founder Command surface
- read-only and draft-only
- sanitized readiness API available
- reusable UI components available
- hidden route not created until owner authentication, device trust, and step-up confirmation are sufficient

## Snapshot Inputs

The Build Room reads:

- Local Day One acceptance gate
- Product Reality final score
- product gap memory
- validation summary memory
- product memory summary
- construction queue
- Codex Task Compiler
- Journal / Coach readiness

## Codex Draft Candidates

Build Room provides draft candidates for:

- visual simplification
- chart polish
- TPM Assistant improvement
- Journal / Coach improvement
- Settings / Diagnostics cleanup
- public entry polish
- Local Day One blocker fix
- regression and smoke test cleanup

Each draft includes mission, scope, forbidden scope, likely files, validation commands, final response format, and Product Truth preservation.

## Hard Boundaries

Build Room must not:

- send tasks to Codex automatically
- execute approvals
- enable live execution
- route real money
- activate billing
- activate broker/feed
- launch publicly
- touch production secrets
- connect social accounts
- publish externally
- fake users, revenue, or metrics
