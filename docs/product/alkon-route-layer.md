# Alkon Route Layer

Route sends each lawful signal to the right owner system.

Route targets include Public Earth, Trading Workspace, Plan Realms, TPM Assistant, Academy, Community, Support, Apps / Platforms, Visual Identity, Shell / Navigation, Planetary Environment, Security Sovereignty, Secrets Authority, Codex Construction, Result Tribunal, Product Memory, Launch Readiness, and Alkon Command.

Every route names:
- owner system
- supporting systems
- responsible worker
- required monitors
- report target
- memory target
