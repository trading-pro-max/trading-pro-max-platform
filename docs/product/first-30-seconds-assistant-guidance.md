# First 30 Seconds Assistant Guidance

TPM Assistant is the natural interface for secondary intent. Essential actions
remain buttons, while questions and experience requests route through Assistant
guidance.

Public prompt examples:
- Start
- Why blocked?
- Bigger chart
- Calmer
- Plans
- Apps
- Support
- Journal

Assistant must explain active, planned, inactive, future, paper-safe, and
blocked states without long generic replies. It may suggest allowed Personal
Reality changes, but it must not activate paid plans, billing, live execution,
real money, broker/feed, social publishing, or private systems.
