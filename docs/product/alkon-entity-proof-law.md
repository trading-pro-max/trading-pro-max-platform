# Alkon Entity Proof Law

Every entity needs proof before acceptance.

Proof may include TypeScript, ESLint, build, regression, smoke route, screenshot, public leak check, Product Truth check, security check, API safety check, visual acceptance, Founder review, legal/guardian review, treasury review, and rollback proof.

Public UI entities require screenshot or public proof. Private Alkon entities require public no-leak proof. API entities require no-secrets and no-private-data proof. Financial entities require invoice/accounting readiness proof. Launch entities require launch gate proof.
