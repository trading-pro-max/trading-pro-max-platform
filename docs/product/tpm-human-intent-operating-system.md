# TPM Human Intent Operating System

Trading Pro Max uses a Human Intent Operating System so users can describe what they want instead of hunting through secondary controls.

Core law:
- Buttons are for immediate essential actions.
- TPM Assistant is for human intent.
- Product Truth decides what is real.
- Plan access decides what can be applied.
- Safety and privacy decide what is blocked.
- Private command systems remain private.

Every user request resolves to one of four outcomes:
- allowed action
- truthful explanation
- safe alternative
- blocked response

The system is local and non-executing. It never activates live trading, real money, broker/feed, billing, launch, social publishing, or private command access.
