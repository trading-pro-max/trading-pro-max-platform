# Clutter Prevention Law

Status: active

Purpose:

Prevent future clutter from being born.

## Rules

- No file without owner.
- No component without product purpose.
- No route without destination and visibility.
- No API without boundary, execution policy, and test/proof.
- No public UI without public-safe language.
- No private Alkon -0 surface without Founder-only containment.
- No report without current path, mission, status, and next action.
- No generated asset, raster file, archive, backup, or runtime cache in active source.
- No future action without Jar classification.
- No Command Passport without Jar exit permit.

## Required Before Adding New Code

New work must answer:

- What layer owns this?
- Is it public, private, invisible, tool, test, doc, report, or asset?
- What route/API/component imports it?
- What test or report proves it?
- What unsafe action is explicitly blocked?
- What is its lifecycle and next fate?

If those answers are missing, the item must be recorded as a cleanup candidate instead of becoming active source.

## Future Guard

The origin-clean reports, route cohesion tests, public leak tests, Product Truth tests, and cleanup candidate report are part of the clutter firewall.
