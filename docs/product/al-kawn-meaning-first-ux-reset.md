# Al-Kawn Meaning-First UX Reset

## Why This Reset Was Needed

Ahmad reviewed `/desktop/kawn` and still did not clearly feel what the screen was. The route had too many project surfaces, queues, Pro Max/trading references, and technical details close to the first experience.

## First Screen Rule

First screen is for الكون only.

The first screen must answer:

- What is this?
- What can الكون do now?
- How does Ahmad command it?
- What does Ahmad control?
- What is the one next action?

## Meaning-First Structure

The first screen has five areas:

1. Identity: `أحمد، هذا هو الكون.` and `الكون هو عالمك الإلكتروني الخاص داخل لابتوبك.`
2. Current abilities: understanding, organizing, internal building, validation, truth/secret protection, reporting, and next-action selection.
3. Command center: `اكتب ما تريد من الكون الآن.`
4. Ahmad controls and Product Truth: money, outside-world action, and secrets remain under Ahmad.
5. One next action: Ahmad reviews the experience, then decides whether to start Local Day One.

## Secondary Surfaces

Pro Max, trading, review queues, technical panels, reports, legal/money queues, and boot details remain preserved but secondary. They move into grouped detail surfaces such as:

- `التفاصيل التقنية`
- `مراجعات مؤجلة`
- `بوابات القانون والمال`
- `Pro Max / Trading Layers`

## Product Truth

The first screen now uses one simple truth strip:

`Product Truth: لا إطلاق عام، لا مال حقيقي، لا بروكر، لا ادعاءات قانونية، لا خروج للأسرار.`

Detailed Product Truth chips remain lower in technical details.

## Local Day One Rule

Local Day One remains not started. Ahmad must review `/desktop/kawn` and decide before `START LOCAL DAY ONE`.
