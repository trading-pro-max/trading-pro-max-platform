# Identity Evolution System

Identity Evolution classifies brand changes before they become Codex tasks or product changes.

## Major Changes

- logo redesign
- plan colors
- public landing visual direction
- VIP identity
- private command visual direction
- occasion themes
- partnership visuals
- Swiss identity changes

Major changes route through:

Design Ministry -> Identity Guardian -> Legal -> Guardian -> Quality -> Founder approval when major.

## Minor Changes

- spacing
- copy cleanup
- reduced clutter
- small state label polish

Minor changes may be safe to draft when they preserve public language, plan truth, reduced-motion safety, chart priority, and product truth.

## Blocked Changes

Any change that implies live execution, real-money routing, broker/feed activation, billing, social publishing, public launch, fake certification, fake partnership, or fake paid-plan activation is blocked.
