# Founder Media Command

Founder Media Command defines how the private Founder Command App will review Media Office and AI Video Studio work without connecting accounts or publishing externally.

## Queues

- content draft queue
- AI video script queue
- campaign calendar
- channel readiness queue
- Guardian review queue
- Legal review queue
- Founder approval queue
- blocked/archived queue

## Content Lifecycle

| State | Meaning |
| --- | --- |
| draft | content exists but is not reviewed |
| guardian_review | Guardian checks abuse, manipulation, scam, and safety risk |
| legal_review | Legal Counsel checks claims and regulated wording |
| ready_for_founder | reviewed item is ready for Founder decision |
| approved | Founder approved the reviewed item |
| scheduled | future state after real publishing system exists |
| published | future state only after real external publishing exists |
| blocked | item cannot proceed |
| archived | retained for record/history |
