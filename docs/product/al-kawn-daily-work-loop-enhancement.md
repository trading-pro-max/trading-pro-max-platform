# Al-Kawn Daily Work Loop Enhancement

## Definition

Daily Work Loop enhancement deepens the awakened private daily operating cycle for الكون.

Required wording:

- Daily Work Loop enhancement
- الكون ينظم يومه الداخلي.
- Today’s internal work is selected.
- Safe internal work can continue.
- Legal and Money gates stop execution for Ahmad.
- Daily blockers are visible.
- Daily WAKE REPORT updated.
- One next action selected.

This is not Infinity Mode, not Operator Mode, and not public launch.

## Enhanced Daily Checklist

The daily loop checks:

- Reality: device time, device date, day/night, season, weather not connected, location not requested.
- Product Truth: public launch blocked, billing inactive, payments inactive, receiving money inactive, real money disabled, broker disabled, legal review pending, ALKON private, الكون private.
- Kernel: Universe Operating Kernel available, execution judge available, Product Truth law available.
- Desktop state: `/desktop/kawn`, local auth, packaging gate, dry run, distribution gate.
- Reports: latest WAKE REPORT, daily report, validation summary, missing reports if any.
- Work selection: one safe internal work item, no legal/money/public/broker/payment/real-trading/secrets exposure.
- Report output: daily report updated, one next action updated, blockers visible.

## Priority Engine

Priority rules:

- Product Truth priority comes first.
- Protection/auth/secret risks second.
- Desktop operating readiness third.
- Reports/docs/tests fourth.
- Visual or comfort improvements after truth/protection.
- Legal and Money tasks are stopped for Ahmad.
- One daily next action only.

## Safe Internal Work

Safe internal work may include:

- project state audit
- report generation
- docs update proposal
- regression summary
- visual consistency review
- desktop status review
- Product Truth verification
- architecture status summary
- next Codex mission draft
- task organization
- daily briefing update
- control surface status review

Each item declares its layer, reason, priority, status, direct-execution permission, stop gate, expected output, and next step.

## Blockers

Daily blockers include:

- legal tasks stopped
- money tasks stopped
- public launch blocked
- billing blocked
- payments blocked
- receiving money blocked
- real money blocked
- broker blocked
- legal approval claim blocked
- public الكون blocked
- public ALKON blocked
- secrets exposure blocked
- Product Truth violations blocked

Each blocker states what الكون can prepare and what Ahmad must decide if relevant.

## Memory Snapshot

The memory snapshot lives at `reports/daily/al-kawn-daily-memory-snapshot.md`.

It includes:

- current date/time source
- latest closed mission
- current daily state
- selected safe work item
- blockers
- next action
- what was not done
- no secrets
