# Local Day Cycle

The Local Day Cycle is the daily Founder review loop for the closed local product.

Stages:
1. Wake / Start
2. Build check
3. Runtime start
4. Public entry review
5. Free/Demo journey review
6. Workstation review
7. Chart review
8. Execution paper review
9. TPM Assistant review
10. Why Blocked review
11. Journal / Coach review
12. Settings review
13. Diagnostics review
14. Product Truth review
15. Visual acceptance review
16. Founder decision
17. Build task creation
18. Validation
19. Git clean / push check
20. End-of-day report
21. Sleep / Archive

Each stage includes purpose, checks, pass criteria, fail criteria, output, and next action in `lib/server/local-ops/day-cycle.ts`.

No stage is a launch criterion. A successful local day proves only local operation.
