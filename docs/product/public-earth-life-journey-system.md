# Public Earth Life Journey System

The public user journey is:

Discovery -> Trust -> Access -> Trade / Practice -> Learn -> Improve -> Support / Grow.

Discovery happens on Home. Trust is built through Product Truth. Access happens through the public shell and Apps / Platforms truth. Trade / Practice happens in the paper-safe workspace. Learn happens through Academy, Assistant, Journal, and Coach. Improve happens through reflection and plan-aware controls. Support / Grow happens through Support, Community readiness, and future plan depth.
