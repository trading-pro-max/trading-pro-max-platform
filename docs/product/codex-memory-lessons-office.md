# Codex Memory & Lessons Office

Memory & Lessons records safe construction patterns and Founder preferences after Result Tribunal review.

Lesson fields:
- task type
- outcome
- reason
- files touched
- risk
- Ahmad feedback
- known repeated mistake
- future rule
- avoid pattern
- accepted pattern

Required lessons:
- no generated images unless explicitly requested
- public logo subtitle rejected
- old logo not accepted
- chart annoyance must be guarded
- Free public simplicity must be protected
- Founder/internal terms must not leak
- no overbuilding Home

Memory must not store:
- secrets
- private sensitive data
- raw sensitive logs
- fake users
- fake revenue
- fake metrics

Lessons inform future task drafting but do not authorize autonomous execution.
