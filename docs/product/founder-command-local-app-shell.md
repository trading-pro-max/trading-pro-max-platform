# Founder Command Local App Shell

The Founder Command Local App Shell is the private local owner surface for Ahmad. It exists so Trading Pro Max can be operated, reviewed, and improved on Ahmad's machine before any global activation.

This shell is not a public product feature. It is not part of Free, Pro, VIP, or Institutional. It is read-only by default and reports readiness, product gaps, local operations, product memory, construction queue state, validation summaries, Guardian/Legal warnings, Treasury/Media readiness, next safe actions, and what not to do.

## Safety Contract

The local command shell must never activate:

- live execution
- real-money routing
- broker/feed activation
- billing
- public launch
- social publishing
- approval execution
- production secret changes

The shell must not contain secrets, private sensitive user data, fake users, fake revenue, fake metrics, fake Pro/VIP/Institutional activation, fake Swiss legal/company status, or fake Islamic/Sharia certification.

## Route Decision

No `/founder/local-command` preview route is created in this pass. The shell is available as reusable private components and sanitized read-only APIs only. A route can be considered later only after owner authentication, device trust, step-up confirmation, and route exposure rules are implemented.

## APIs

- `/api/founder/local-command/snapshot`
- `/api/founder/local-command/readiness`

Both are readiness-only, no-store, non-secret, non-private-data, non-metric, and non-execution routes.
