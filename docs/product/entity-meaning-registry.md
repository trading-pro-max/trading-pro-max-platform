# Entity Meaning Registry

The Meaning Registry explains why each entity exists.

It answers:
- why does this entity exist?
- who does it serve?
- what happens if it is removed?
- what value does it provide?
- is it public, private, or invisible?
- should it stay, improve, deprecate, or be removed?

Public entities must serve user clarity, access, learning, support, trust, or workspace.

Private Alkon entities must serve Founder control, construction, safety, memory, or reporting.

Invisible layer entities must serve truth, safety, mapping, entitlement, context, or protection.
