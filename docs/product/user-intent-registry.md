# User Intent Registry

The public registry lives in `lib/server/intent-interface/intent-registry.ts`.

Public intent categories:
- discovery
- workspace
- chart
- paper execution
- learning
- support
- plan
- apps/platforms
- environment
- accessibility
- Personal Reality
- safety
- blocked

Private Founder-only intents exist for private command readiness, but they are not available in the public TPM Assistant.
