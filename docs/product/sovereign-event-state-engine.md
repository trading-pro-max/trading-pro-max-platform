# Sovereign Event State Engine

The event engine defines event categories, statuses, risk levels, severity, Product Truth impact, public impact, Founder impact, required reviews, suggested owner, next action, and lifecycle status.

Statuses:

- observed
- classified
- routed
- waiting_review
- waiting_founder
- draft_ready
- permit_pending
- permitted
- blocked
- result_pending
- completed
- archived

Blocked categories include billing, live execution, broker/feed, real money, social publishing, public launch, secrets risk, security risk, Product Truth conflict, internal language leak, and public/private boundary risk.
