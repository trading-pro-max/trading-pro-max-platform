# Multi-Device Reality System

Trading Pro Max is not one interface copied onto every screen. It is a multi-device reality system: each device has a role, permission level, interface density, security posture, continuity path, public/private boundary, and launch-readiness state.

Core law:

- Each device is a different window into the same Product Truth.
- Public devices serve users on Earth.
- Private devices serve Founder command inside Alkon.
- No device can bypass safety, privacy, permissions, or Founder authority.
- No device activates production, billing, broker/feed, live execution, real money, social publishing, or external accounts.

Public devices:

- Trading Pro Max Web App: current.
- Trading Pro Max Desktop App: planned.
- Trading Pro Max Mobile App: planned.
- Trading Pro Max Tablet App: future.

Private Founder devices:

- Alkon Desktop Command: internal command readiness.
- Alkon Pocket Universe OS: planned private mobile pulse.
- Alkon Tablet Review: future visual/report review.
- Alkon Watch Alerts: future P0 alerts only.

The invisible operating layer keeps Product Truth, permissions, memory, safety, and readiness consistent across all devices without leaking private systems to normal users.
