# Contextual Actions System

Contextual actions are visible only where they are immediately useful.

Workspace contextual actions:
- paper buy
- paper sell
- AI wait
- Why Blocked
- change symbol
- switch timeframe
- reset chart
- open TPM Assistant

Journal/Coach contextual actions:
- save journal note
- open Coach

Everything else should be explained or previewed through TPM Assistant unless it becomes a direct task with clear, immediate value.
