# Local Day One Convergence

Local Day One is the first daily local operating loop after final convergence.

Loop:

1. Review the public Earth World.
2. Review the Trading Workspace and chart comfort.
3. Review TPM Assistant and Journal/Coach.
4. Capture Founder ideas.
5. Classify ideas into governed events.
6. Generate Task Passport previews.
7. Draft Codex prompts for manual external execution only.
8. Wait for external/manual execution.
9. Run validation.
10. Send result to tribunal.
11. Update memory.
12. Prepare the next day plan.

Local Day One does not authorize global launch, production, billing, broker/feed, live execution, real money, social publishing, or uncontrolled automation.

Before Local Day One acceptance:

- Full validation must pass.
- Public/private boundary checks must pass.
- Visual proof must be reviewed.
- Codebase Reality Audit and Safe Cleanup must remain explicit, governed steps.
