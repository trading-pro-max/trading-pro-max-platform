# Private Planet Command World

The private world is the Founder-only command surface for Ahmad.

It may show:

- Founder Command
- Planet Command
- Local Operations
- Sovereign Autonomy
- Construction Queue
- Codex Governance
- Product Memory
- Result Tribunal
- Secrets Authority
- Security Sovereignty
- World Interface
- Treasury
- Media
- Ministries / Councils / Governance
- Founder Idea Inbox

The private world is read-only by default. It reports readiness, reviews, blocked states, task passports, Codex drafts, memory, tribunal outcomes, and next safe actions.

It must not:

- execute approvals
- execute shell commands
- call Codex directly
- activate billing
- connect broker/feed
- enable live execution
- route real money
- publish socially
- expose secrets
- expose itself to public users or plan features
