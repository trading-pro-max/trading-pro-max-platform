# Orbit Path System

Orbit Path routes a cosmic event through Alkon.

## Orbits

- public_ui_orbit
- visual_identity_orbit
- chart_workspace_orbit
- assistant_orbit
- journal_coach_orbit
- plans_realms_orbit
- apps_support_orbit
- security_orbit
- secrets_orbit
- codex_construction_orbit
- media_world_interface_orbit
- memory_orbit
- local_day_orbit
- launch_forbidden_orbit

Each orbit defines purpose, allowed events, forbidden events, owner planets, satellites, stations, required reviews, validation, and memory update.

Black-hole events do not progress to construction. They are reported as blocked with a safe alternative.
