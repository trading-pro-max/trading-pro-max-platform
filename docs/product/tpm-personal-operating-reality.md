# TPM Personal Operating Reality

Personal Operating Reality turns themes into plan-aware operating experiences.

Flow:
User intent -> TPM Assistant understanding -> Plan Realm check -> Product Truth check -> Safety / Privacy check -> Allowed Personal Reality settings -> Preview / explanation -> Apply allowed changes or explain why not.

This does not activate paid plans, billing, live execution, broker/feed, real money, production, social publishing, or private systems.

Free active profiles:
- Clean Earth.
- Calm Workspace.
- Chart Comfort.
- Static Mode.
- Low Motion.
- High Contrast.
- Learning Basics.

Pro, VIP, and Institutional profiles remain planned, locked, or future unless real entitlement gates exist.
