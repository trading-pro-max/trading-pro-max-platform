# Ministry Ownership Resolver

The ownership resolver maps each construction event to internal ownership and review routing.

Examples:
- chart/workstation/UI -> Product Quality, Markets/Trading, Engineering
- Assistant/context -> Personal Companion, AI/IQ/Brain, Guardian/Legal when risky
- plan wording/entitlements -> Treasury, Legal, Guardian, Quality
- media/content -> Media, Legal, Guardian, Founder when sensitive
- billing/monetization -> Treasury, Legal, Founder
- live/broker/feed -> Markets, Engineering, Guardian, Legal, Founder, blocked currently
- secrets/production -> Ops, Security, Founder, blocked currently
- public language leakage -> Brand/Rights/IP, Legal, Quality
- journal/coach -> Coaching/Journal, Legal, Guardian, Quality

The resolver returns owner ministry, supporting ministries, required reviews, escalation target, Founder visibility, and user visibility.
