# Integration Priority Law

Trading Pro Max integration planning follows strict priority law.

## P0 Local Required

P0 items are required to keep local construction honest:

- local runtime
- Git/GitHub readiness
- Codex task workflow
- diagnostics
- product memory
- validation commands
- Founder Command readiness

## P1 Soon

P1 items are needed soon, but still readiness-only:

- email readiness
- support readiness
- secrets readiness
- security readiness
- apps/platforms readiness

## P2 Pre-Launch

P2 items must wait for pre-launch review:

- staging hosting
- managed database
- email provider
- monitoring
- payment provider readiness
- public waitlist

## P3 Post-Launch

P3 items are future growth and operations systems:

- social publishing
- advanced CRM
- partnerships dashboard
- ads
- affiliate/referral

## Blocked Now

The following are forbidden during local operation:

- billing activation
- broker/live execution
- real-money routing
- production secrets
- automatic social publishing
- external autopilot
