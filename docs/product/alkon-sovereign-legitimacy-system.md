# Alkon Sovereign Legitimacy System

Alkon Sovereign Legitimacy is the private Founder-only layer that checks whether an intended action deserves to exist before authority is used.

Authority proves who may decide. Legitimacy proves whether the decision is mission-aligned, truthful, useful, safe, lawful, financially controlled, correctly timed, reputation-safe, reversible where needed, and owned by Founder responsibility.

It is read-only readiness. It does not launch, bill, trade live, route real money, publish, send email, call Codex, execute shell commands, store secrets, or store bank/card data.
