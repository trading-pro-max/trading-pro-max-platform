# Earth Place / Privacy Layer

Trading Pro Max must not use GPS, precise location, hidden tracking, or exact-location storage for public atmosphere or Personal Reality.

Allowed:
- Browser time.
- Timezone.
- Locale.
- Country-level or manually selected region/city only when explicit and optional.

Not allowed:
- GPS prompts.
- Precise tracking.
- Hidden location collection.
- Weather/location as trading advice.
