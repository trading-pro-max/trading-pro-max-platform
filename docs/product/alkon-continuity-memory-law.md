# Alkon Continuity Memory Law

Every continuity decision creates memory.

Memory preserves lessons, Founder preferences, repeated mistake prevention, future guardrails, validation expectations, public/private boundaries, and report targets. It must never store secrets, raw private sensitive data, bank/card data, fake users, fake revenue, or fake metrics.

Required memory rules include no generated images unless explicitly requested, no raster assets, no public Alkon exposure, no fake activation, no fake claims, no fake downloads, chart-first workspace, single shell, complete Free experience, plan realms as function not color, and no removal without dependency and rollback proof.
