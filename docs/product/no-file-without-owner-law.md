# No File Without Owner Law

Status: active

Every active file must belong to one primary owner layer:

| Layer | Owns |
| --- | --- |
| Public Pro Max Reality | Public routes, public shell, Pro Max Center, Pro Max Trading, user-safe product surfaces |
| Private Alkon -0 | Founder routes, Alkon command interface, Founder APIs, Jar Build System, private operating systems |
| Public Pro Max | Public routes, public shell, Pro Max Center, Pro Max Trading, user-safe product surfaces |
| Invisible Operating Layer | Product Truth, public-safe translators, security/readiness summaries |
| Tools / Builder | Terminal-only scripts, local builder, Prisma local support |
| Tests / Evidence | Regression specs, smoke harnesses, screenshots, proof artifacts |
| Docs / Reports | Doctrine, architecture law, wake reports, audit reports |
| Public Assets | Approved static assets only |

Files with unclear ownership are not deleted by default. They are classified as cleanup_candidate, move_candidate, archive_candidate, protected, blocked, or needs_ahmad_decision.

Permission-to-Exist amendment: every file must also prove purpose, visibility, safe boundary, evidence or documented reason, lifecycle, and next fate. If any answer is missing, the file enters Jar / Inbox instead of execution.
