# Identity Governance

Identity governance protects Trading Pro Max from confusing visuals, unsafe claims, competitor copying, and public/internal language leaks.

## Review Route

Major identity changes route through:

1. Brand / Rights
2. Legal
3. Guardian
4. Quality
5. Founder approval when the change is major, public-facing, claim-sensitive, or plan-sensitive

## Changes Requiring Review

- logo shape, animation, or state semantics
- public plan naming
- VIP or Institutional wording
- public launch wording
- Swiss wording
- Islamic/Sharia wording
- pricing, billing, or monetization language
- partnership or brand references
- social/media campaign identity
- Founder/internal command identity exposure

## Automatic Blocks

Identity work cannot:

- enable live execution
- enable real-money routing
- activate broker/feed
- activate billing
- publish externally
- use production secrets
- claim Swiss legal/company status
- claim Islamic/Sharia certification
- use competitor branding
- expose Founder/internal command surfaces to normal users

## Acceptance

Automated tests can guard selectors, wording, state truth, and no-raster dependency. Final visual acceptance remains a human Ahmad review.
