# Pro Max Truth Safety Proof Law

Truth blocks false claims.

Forbidden without future independent proof, legal readiness, and Founder
approval:

- public number-one or best claims
- global financial center claims
- licensed or regulated claims
- profit promises
- win-rate claims
- fake app downloads
- fake support backend
- fake users, revenue, or metrics
- fake Swiss company, legal, partnership, or certification claims
- fake live, real-money, broker/feed, billing, or launch status

Safety blocks harm.

Forbidden now:

- secrets exposure
- bank/card data
- shell execution from the web app
- direct Codex execution from the web app
- public Alkon exposure
- live execution
- real-money routing
- broker/feed activation
- billing activation
- production activation
- hidden precise tracking
- regulated financial action without review

Proof is required before closure:

- TypeScript
- ESLint
- build
- prisma validate
- regression tests
- smoke routes
- Product Truth check
- public leak check
- screenshots for UI or visual work
- git clean
- commit hash
- push status
- Founder visual acceptance when required
