# Planet Blueprint Engine

The Planet Blueprint Engine defines the official TPM Planet OS structure.

Runtime source:

- `lib/server/planet-os/blueprint.ts`
- `/api/planet/blueprint`

It reports:

- planet
- continents
- states
- ministries
- cities/modules
- professions/workers
- citizen classes
- readiness, risk, automation, owner, report destination
- active, planned, and blocked truth

It does not report fake users, fake revenue, fake metrics, secrets, launch state, billing activation, broker/feed activation, or live execution.

The blueprint exists to help build the product faster without turning planned systems into active claims.
