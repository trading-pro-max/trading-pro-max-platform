# Founder Sovereign Autonomy Room

The Founder Sovereign Autonomy Room is a private Founder Command surface showing:

- Sovereign Autonomy status.
- Incoming Founder ideas.
- Event queue summary.
- Blocked events.
- Tasks waiting review.
- Tasks waiting Founder approval.
- Task Passports ready.
- Codex drafts ready.
- Permit decisions.
- Result Tribunal outcomes.
- Memory lessons.
- Next safe action.
- What not to automate.
- Public/private boundary status.
- Product Truth status.

It is owner-only, read-only, not exposed to public navigation, and not available as a user plan feature.
