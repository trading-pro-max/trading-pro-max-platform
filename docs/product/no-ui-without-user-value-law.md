# No UI Without User Value Law

Every UI surface must provide public user clarity, product truth, paper-safe trading utility, support or learning value, Founder-only decision value, or evidence/proof value.

No UI may exist just because a file exists.

No public UI may expose private Alkon language.

No private UI may pretend to be a public product.

No UI may activate billing, live trading, real money, broker/feed, production, shell, Codex, payments, or external accounts.
