# First 3 Minutes Workspace Usefulness

Trading Workspace must prove the product is useful quickly.

Required behavior:
- one terminal shell only
- no public navigation row inside Workspace
- one compact brand mark
- chart is dominant
- paper execution rail is clear
- Assistant is compact and non-blocking
- Journal / Coach are secondary
- no noisy overlays
- no fake live data
- no internal terms
- dark/light/adaptive readable
- RTL stable

If deeper market-pulse polish is still needed, mark
workspace_chart_pulse_polish_needed. Do not claim the market workspace is final
without visual proof and human acceptance.
