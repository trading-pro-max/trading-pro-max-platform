# Public User World

The Public User World is the simple, professional Trading Pro Max product surface.

It contains:

- Home
- Trading Workspace
- Markets
- Plans
- Apps / Platforms
- Academy
- Community
- Support
- Settings
- Diagnostics

Public UI must stay chart-first, calm, premium, and easy to understand. It may explain blocked, inactive, planned, paper-safe, fallback, and not-certified states, but it must not expose private command systems or internal operating terminology.

## Public Navigation Rules

Public navigation may link to Home, Trading Workspace, Markets, Plans, Apps / Platforms, Academy, Community, Support, Settings, and Diagnostics.

Public navigation must not link to Founder Command, local operations, construction queue, product memory internals, secrets authority, security sovereignty internals, treasury controls, approvals, or Codex tasks.

## Public Diagnostics Rules

Diagnostics is a user-safe readiness center. It may show:

- System readiness
- Trading Workspace readiness
- Assistant readiness
- Journal/Coach readiness
- Plan readiness
- Safety status
- Service availability
- Product Truth summary

Diagnostics must not become an internal control room.

## Public Assistant Rules

TPM Assistant uses public language only. It can explain plan access, blocked states, paper mode, settings, diagnostics, feedback, Journal/Coach, and safe learning. It cannot reveal private command systems, secrets, construction queues, internal readiness details, or restricted controls.
