# Alkon Activation Law

Alkon Operating Mode may activate only as a private, evidence-led operating layer.

Activation gates:
- Product Truth Gate
- Public/Private Boundary Gate
- Build Validation Gate
- Git Clean Gate
- Wake Report Gate
- Living Market Core Gate
- Visual Acceptance Gate
- Assistant Readiness Gate
- Settings and Diagnostics Gate
- Alkon Private Readiness Gate
- Local Day One Gate

P0 Product Truth, security, public leak, failed validation, and dirty Git block activation. Visual acceptance pending does not block Operating Mode activation, but it blocks Local Day One start.

Activation is not production launch. It does not activate live execution, real money, broker/feed, billing, public launch, social publishing, regulated services, external accounts, shell execution, or uncontrolled automation.
