# Codex Task Compiler

The Codex Task Compiler turns safe construction events into Codex-ready draft prompts.

It includes:
- mission and objective
- current baseline
- scope and likely files
- forbidden scope
- Product Truth requirements
- public language rules
- safety rules
- Guardian/Legal requirements
- Founder approval requirement
- acceptance criteria
- validation commands
- screenshot requirements when visual
- final response format
- rollback/cleanup rule
- expected commit message

It does not:
- send tasks externally
- run Codex automatically
- execute code
- bypass Founder/Guardian/Legal review
- create production actions

Execution truth: draft_only_not_sent_not_executed.
