# Founder Command Visual Direction

The Founder Command App should feel like a serious private command instrument, not a game, fantasy surface, or public dashboard.

## Identity

- black, graphite, and controlled gold
- Swiss-inspired precision
- calm command-room hierarchy
- strong typography
- compact status language
- clear risk color discipline
- no crowns as decoration
- no fantasy maps
- no childish visuals
- no clutter

## Desktop Direction

Desktop may support a multi-panel command dashboard, but panels must remain controlled and purposeful.

Recommended zones:

- Planet overview
- Founder approval queue
- Guardian and Legal queues
- Ops Tower state
- Engineering gaps
- Treasury readiness
- Media and AI Video queue
- blocker stack
- audit/recovery notes

## Mobile Direction

Mobile is not a compressed desktop dashboard. It should show:

- urgent alerts
- approval cards
- daily summary
- approve / reject / review later actions
- risk level
- review status
- next safe action

## App Icon Direction

Use the Trading Pro Max mark as a simple SVG source:

- hexagon or shield-style trading mark
- three market bars or candles
- controlled growth signal
- gold on graphite for dark app surfaces
- graphite on light background for light surfaces

No raster AI dependency is required for the command app foundation.

## State Styling

- Low: calm neutral/blue
- Medium: amber review state
- High: gold/amber with clear Founder approval label
- Critical: red blocked state
- Inactive/planned: muted graphite state

The app must never make blocked systems look active.
