# Founder King Command Room

The Founder King Command Room is the future private owner-only command environment for Ahmad. It is not a public route, not a normal admin page, and not available to Free, Pro, VIP, or Enterprise citizens.

In the Planet OS model, this room is the private planetary command surface. It lets the Founder King observe the whole Trading Pro Max planet, review system queues, and approve high-risk actions without exposing owner controls to citizens or public routes.

## Sensitive Action Rules

Read-only by default. Any action that changes claims, entitlements, activation gates, media publishing, billing, broker/feed state, public launch, secrets, or user access requires:

1. clear preview
2. risk classification
3. Founder confirmation
4. audit event
5. rollback note where applicable

Critical actions remain blocked until production systems, credentials, legal review, and explicit release paths exist.

## Planet OS Boundary

The Command Room may coordinate the planet, but it must not become a hidden bypass. Founder authority can approve high-risk reviewed actions, but cannot make false claims true, cannot expose secrets, cannot activate real-money routing without configured gates, and cannot turn planned systems into active systems by wording alone.
