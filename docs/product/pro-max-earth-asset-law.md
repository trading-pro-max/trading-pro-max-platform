# Pro Max Earth Asset Law

The Living Earth Runtime may not use random assets, unknown-license assets, hotlinked images, generated images, or unapproved raster files.

Approved local licensed Earth textures may be used only when a manifest entry includes:
- source
- license
- author
- usage notes
- Ahmad approval
- checksum
- enabled state
- local path

If no approved texture exists, Pro Max must use procedural, SVG, CSS, and React rendering. The product must state internally that procedural fallback is not full photorealism.

Public users may see fallback or approved texture status only in public-safe language. License internals remain private.
