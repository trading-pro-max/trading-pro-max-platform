# Founder Command Desktop App

The Founder Command Desktop App is the future full private command surface for Ahmad on Windows, macOS, and Linux.

This document defines readiness only. No installers, packages, app signing, update channel, or native runtime are shipped by this foundation.

## Desktop Purpose

Desktop is the full Founder control surface because it can support dense review, queue comparison, audit inspection, and careful approval workflows without forcing mobile-style compression.

It should eventually include:

- Planet overview dashboard
- Founder approval queue
- Guardian alerts
- Legal review queue
- Media campaign queue
- AI Video Studio queue
- Ops health
- Engineering tasks
- Feedback triage
- Treasury controls
- Pro and VIP readiness
- citizen overview
- Community moderation overview
- production blockers
- secret rotation readiness
- safety boundaries dashboard

## Device Targets

- Windows
- macOS
- Linux

## Desktop Interaction Rules

- read-only by default
- sensitive actions require explicit confirmation
- high-risk approvals require clear preview and audit
- critical actions remain blocked
- no secrets shown in UI
- no fake live metrics
- no fake users, revenue, followers, or billing state

## Future Desktop Shell Requirements

- private owner sign-in
- local device trust state
- lock-on-idle behavior
- visible environment state
- clear offline/reconnect state
- audit trail visibility
- command search for reviewed items only
- no public citizen workstation controls

## Current Truth

Desktop command architecture is defined. A real native desktop application is not shipped.
