# Reality Conversion Resource Law

Everything and anything may be considered as a resource only when it is safe, lawful, useful, evidence-backed, and Product Truth preserving.

Allowed resources:
- code changes
- docs
- reports
- tests
- screenshots
- local builder tools
- approved local licensed assets
- public-safe user feedback

Forbidden resources:
- unknown-license assets
- hotlinked images
- generated assets without approval
- secrets
- bank/card data
- shell execution from web
- Codex execution from web
- payment execution
- live trading
- broker/feed activation
- billing activation
- fake legal, regulatory, profit, or win-rate claims
