# Founder Acceptance Loop

Founder Acceptance is the daily decision memory for Ahmad's local review of Trading Pro Max.

## Supported States

- `accepted`
- `needs_polish`
- `confusing`
- `too_much`
- `missing`
- `blocked_by_design`
- `future`

## Review Surfaces

- Public entry.
- Trading Workspace.
- Chart.
- Paper execution.
- TPM Assistant.
- Journal / Coach.
- Settings.
- Diagnostics.
- Plan clarity.
- Visual identity.
- Local operation.

## Rules

- Ahmad human visual acceptance is required for final visual approval.
- Acceptance notes are safe summaries only.
- Acceptance does not approve launch, billing, broker/feed activation, live execution, real-money routing, social publishing, production activation, or secret changes.
- Founder Command remains private and is not a user plan feature.

## Daily Use

1. Review the surface.
2. Pick one acceptance state.
3. Record a concise note.
4. Record the next safe action.
5. Convert actionable gaps into a scoped Codex draft when useful.
