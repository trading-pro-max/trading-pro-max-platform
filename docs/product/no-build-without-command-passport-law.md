# No Build Without Command Passport Law

No governed build starts directly from an idea, rejection, bug, or instruction.

Build order:

1. Enter Jar.
2. Classify owner, risk, visibility, and fate.
3. Pass Reality Trial.
4. Receive exit permit.
5. Draft Command Passport.
6. Execute only the allowed scope.
7. Validate.
8. Produce evidence.
9. Update memory.

Command Passport is preview-only inside Alkon Chat and Founder Command. It does not execute shell, Codex, payments, billing, live trading, broker/feed, real money, production, or external accounts.
