# Adaptive Atmosphere

Adaptive Atmosphere is the public name for the planetary environment system.
It adjusts visual mood by time, selected broad region or timezone, system state,
manual weather preference, plan realm, and user motion preference.

User controls:
- System
- Adaptive
- Solar
- Weather
- Light
- Dark
- High Contrast
- Static

Static Mode disables atmospheric motion. Reduced Motion follows device
preference and also disables motion. High Contrast prioritizes readability over
planetary styling.

Adaptive Atmosphere is not a trading signal and does not affect paper or live
execution. Live execution remains blocked.
