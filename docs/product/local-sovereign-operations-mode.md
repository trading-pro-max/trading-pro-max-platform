# Local Sovereign Operations Mode

Local Sovereign Operations Mode is the internal readiness state for running Trading Pro Max safely on Ahmad's machine.

Purpose:
- review public entry, workspace, chart, execution, TPM Assistant, Journal, Coach, Settings, and Diagnostics locally
- keep all risky capabilities blocked
- collect Founder acceptance decisions
- prepare scoped local build tasks
- validate changes before commit and push

Rules:
- no production actions
- no public launch action
- no billing action
- no live execution action
- no broker/feed activation
- no social publishing
- no secrets in Git
- no fake Pro, VIP, or Institutional activation

Local maturity is useful evidence, not launch authority.
