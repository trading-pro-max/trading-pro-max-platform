# Alkon Action Layer

Act prepares safe action only.

Allowed actions:
- report only
- create Task Passport preview
- create Codex draft preview
- request Founder review
- request Legal, Guardian, or Security review
- create cleanup candidate
- create visual review
- update memory rule
- quarantine
- block

Forbidden actions:
- shell execution
- direct Codex calls
- external API calls
- account creation
- email sending
- social publishing
- billing activation
- broker/live activation
- secrets access
