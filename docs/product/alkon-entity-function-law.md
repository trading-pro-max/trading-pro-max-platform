# Alkon Entity Function Law

Every entity must have a function. Allowed functions include explain, guide, protect, build, validate, report, learn, support, improve trust, reduce risk, reduce clutter, prepare launch, preserve memory, route intent, and guard truth.

If function is unclear, vanity-driven, clutter-producing, or hype-driven, the entity becomes review required, delayed, deprecated, or blocked.

No entity remains only because it exists. It must serve Earth users, Founder command, invisible safety, Product Truth, learning, support, trust, or operational clarity.
