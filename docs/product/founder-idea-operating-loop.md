# Founder Idea Operating Loop

Founder ideas may come from manual notes, visual feedback, local day review, product gaps, assistant notes, or validation results.

Required fields:

- ideaId
- title
- rawIdea
- summary
- source
- affectedWorld
- affectedSurface
- suspectedCategory
- urgency
- founderIntent
- createdAt

Examples:

- "الشعار لا يعجبني" -> logo_rejection_detected / brand_identity
- "الشارت مزعج" -> chart_quality_low / workstation
- "أين تطبيق الموبايل؟" -> apps_platforms_gap / apps_platforms
- "لا أريد صور" -> founder preference memory, no-images rule
- "أريد Codex ينفذ" -> codex_task_needed / codex_governance
- "أريد billing" -> billing_requested / blocked activation

Secrets and private sensitive data are rejected or redacted. Intake does not call external services.
