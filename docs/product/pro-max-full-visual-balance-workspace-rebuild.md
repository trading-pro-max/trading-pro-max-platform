# Pro Max Full Visual Balance and Trading Workspace Rebuild

Status: active public visual contract

Mission: keep Pro Max visually unified as an Earth-native financial product while rebuilding the Trading Workspace around a chart-first hierarchy.

## Core Visual Origin

All public surfaces derive from one origin:

- realistic procedural Earth identity
- atmosphere, light, shadow, and calm financial depth
- chart heartbeat as the workspace center
- Pro Max Assistant as the language layer
- Journal / Coach as a quiet reflection layer
- Product Truth as a compact trust layer

No public surface may introduce a disconnected fantasy, casino, crypto-toy, or fake-premium visual language. Public UI must stay code-only for this pass: no PNG, JPG, WebP, GIF, video, generated image file, or unknown-license asset.

## Public Header Contract

The public header is an orientation layer, not a control panel.

Allowed:

- compact Pro Max logo / wordmark
- Home
- Trading Workspace
- Markets
- Plans
- Apps / Platforms
- Support
- Sign in

Not allowed:

- language controls
- theme controls
- environment controls
- diagnostics/settings utility links
- status/readiness badge clusters
- duplicate rows
- internal or private terms

The header uses a three-zone layout: identity, centered navigation, and Sign in. The center zone must remain optically centered on desktop.

## Trading Workspace Architecture

The workspace architecture is:

TradingWorkspacePage -> WorkspaceHeader -> WorkspaceMarketSummary -> TradingCoreGrid -> ChartArea + ExecutionRail -> AssistantDock -> JournalCoachDock.

Workspace rules:

- no public navigation inside workspace
- one terminal header only
- one compact Pro Max logo only
- chart starts high and dominates the page
- execution rail is integrated on the right
- assistant is collapsed by default
- Journal / Coach is secondary
- Product Truth is compact
- Earth identity supports the page without covering the chart

Hierarchy: Chart > Execution > Truth > Assistant > Journal/Coach > Atmosphere > Brand.

## Product Truth

Pro Max remains paper-safe. Live execution, real-money routing, broker/feed activation, billing, and production launch remain inactive or blocked. Assistant and Journal/Coach provide orientation, explanation, and reflection only; they do not provide financial advice, trading signals, or profit promises.
