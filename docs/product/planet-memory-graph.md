# Planet Memory Graph

The product memory graph links safe product knowledge across features, files, screens, tests, docs, risks, plans, ministries, decisions, Founder preferences, visual acceptance notes, blocked states, and sensitive areas.

Examples:
- chart dominance links workstation, visual acceptance, screenshots, CSS, user trust, and Founder preference
- public language links Free/Pro/VIP/Institutional naming and no internal governance leakage
- TPM Assistant links Product Truth, Plan Entitlements, State Explanations, Guardian, and Legal

Rules:
- no private user data
- no secrets
- no surveillance
- readiness-only model
