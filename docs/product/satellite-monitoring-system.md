# Satellite Monitoring System

Satellites observe signals and evidence before work is assigned.

Satellites include:
- Public UI Satellite
- Logo Satellite
- Chart Satellite
- Workstation Satellite
- Assistant Satellite
- Product Truth Satellite
- Public Boundary Satellite
- Security Satellite
- Secrets Satellite
- Validation Satellite
- Screenshot Satellite
- Memory Satellite
- World Interface Satellite
- Local Day Satellite

Each satellite declares what it monitors, required evidence, reporting target, and validation rule.

Examples: Chart Satellite monitors chart visibility, clutter, overlays, contrast, screenshots, and user rejection. Logo Satellite monitors no-images preference, Earth concept, forbidden subtitle avoidance, compact readability, and plan identity.
