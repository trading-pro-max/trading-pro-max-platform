# Device Security Posture

Security posture levels:

- public_safe
- account_required
- trusted_device_required
- step_up_required
- biometric_planned
- passkey_planned
- internal_only

Public devices stay public-safe and paper-safe. Future public desktop/mobile/tablet surfaces require truthful availability language and account/session readiness before any deeper continuity claim.

Founder devices require readiness for:

- trusted device
- passkey/WebAuthn
- biometric/PIN
- session timeout
- step-up confirmation
- audit trail
- no secret values

This pass does not implement real biometrics, passkeys, device registration, or production auth changes. It creates the model and readiness boundaries only.
