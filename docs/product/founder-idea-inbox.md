# Founder Idea Inbox

Founder Idea Inbox is a private/internal Founder Command surface for Ahmad to preview ideas before they become construction work.

Flow:
1. Founder Idea Input
2. Sovereign Autonomy Idea Intake
3. Event Classification
4. Owner Routing
5. Policy Gates
6. Task Passport Preview
7. Execution Permit Preview
8. Codex Draft Preview
9. Construction Queue Readiness
10. Founder Command Report

Input fields:
- title
- rawIdea
- affectedWorld
- affectedSurface
- urgency
- founderIntent
- desiredTiming
- notes

Allowed affected worlds:
- public_user_world
- private_founder_world
- invisible_operating_layer

Allowed surfaces:
- public_entry
- trading_workspace
- chart
- execution
- assistant
- journal_coach
- settings
- diagnostics
- plans
- apps_platforms
- academy
- community
- support
- founder_command
- security
- secrets
- world_interface
- media
- construction

Safety:
- preview-only
- no persistence
- no secrets
- no private sensitive data
- no external calls
- no shell execution
- no direct Codex execution
- no auto-submit
- permit preview only; no approval execution
- no billing, broker/feed, live execution, real money, social publishing, or public launch activation

Public boundary:
- not public navigation
- not a Free, Pro, VIP, or Institutional feature
- not visible to normal users
- private terminology remains inside Founder Command, private APIs, and docs
