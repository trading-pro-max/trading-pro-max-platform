# Alkon Judgment Layer

Judge evaluates results through the private Result Tribunal.

Checks include:
- tsc pass
- eslint pass
- build pass
- prisma pass
- regression pass
- smoke pass
- git clean
- push state when required
- changed files match scope
- forbidden files untouched
- no public internal terms
- no secrets
- no fake activation
- no images or raster assets
- visual proof when required

Judgment outcomes include accepted, needs fix, rejected, scope violation, Product Truth violation, public boundary violation, security violation, visual review required, Founder review required, and blocked.
