# Alkon Multi-World Constitution

Every future world inherits the shared constitution: Product Truth, Security,
Secrets, Treasury, Legal Gates, Media Claims Firewall, Memory, Founder Authority,
Codex Governance, Result Tribunal, Assistant Intent Layer, Device Readiness,
Launch Gates, and Public/Private Boundaries.

If a future world cannot use shared services, it needs review. No future world
may create an exception path around Product Truth, security, law, money,
privacy, claims, or Founder authority.
