# TPM Brain Context Layer

The TPM Brain Context Layer is the bounded intelligence contract for Trading Pro Max. It combines product truth, plan state, skill profile, journal/coach readiness, Planet OS readiness, Guardian/Legal boundaries, visual acceptance, and state explanations into one safe decision-support snapshot.

Current runtime:
- `lib/server/brain/context.ts`
- `lib/server/brain/types.ts`
- `/api/brain/context`

Allowed context:
- selected route, symbol, and timeframe
- fallback-first market/feed truth
- paper/live/blocked product truth
- plan entitlement and assistant tier
- safe user skill profile defaults
- journal/coach and decision replay readiness
- Planet OS ministry/reporting readiness
- Guardian/Legal and visual acceptance summaries

Blocked context:
- secrets
- broker credentials
- production secrets
- private sensitive user data
- fake users, revenue, or metrics
- fake win rate
- predictive certainty

The Brain may support platform explanation, paper-mode decision support, learning prompts, Founder readiness summaries, and safety cautions. It must not provide financial advice, guaranteed signals, win-rate claims, auto-trading, real-money enablement, or broker/feed activation.
