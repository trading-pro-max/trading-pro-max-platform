# Alkon World Interface

World Interface represents readiness for email, social, support, partners, media, legal, and security channels.

Current state is readiness-only:
- no email sending
- no social publishing
- no connected accounts
- no tokens
- no external automation
- no spam automation
- no fake metrics

## Founder Use

Alkon may show channel readiness, quarantine state, draft-only responses, partner/media/security classification, and legal/Guardian queues.

It must not send messages, publish externally, create accounts, connect social accounts, store tokens, or imply public launch.
