# Alkon Entity Integration Law

Every entity must connect to an owner system, Product Truth, a memory rule, a validation rule, a report target, public/private boundary law, dependencies, dependents, tests, and docs where needed.

Workspace entities connect to Product Truth, Assistant, Journal/Coach, chart tests, and visual proof. Assistant intents connect to Product Truth, plan entitlements, and response tests. Treasury entities connect to financial legitimacy, audit readiness, and no bank/card data. Media entities connect to claims firewall and publishing gate. Alkon entities connect to private no-leak tests.

Orphaned, ownerless, circular, or public/private risky entities cannot be accepted.
