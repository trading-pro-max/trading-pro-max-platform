## Purpose

This policy governs visual assets used by Pro Max and ALKON surfaces. Assets may improve realism and premium feel only when they remain local, lawful, documented, and truthful.

## Allowed

- Original procedural SVG assets created inside the project.
- CSS, SVG, React, and canvas-style visuals created inside the project.
- Local texture files only when source, license, author/provider, checksum, usage notes, approval, and restrictions are complete.
- Local procedural overlays for Earth, atmosphere, clouds, stars, seasons, data nodes, and Swiss-inspired precision grids.
- Visual proof screenshots under `test-results`.
- Web Audio API generated soundscape when off by default and user activated.

## Forbidden

- Random external assets.
- Hotlinked images, videos, textures, or audio.
- Unknown-license files.
- Copied space-agency logos, identity, or branding.
- Official Swiss coat of arms or government symbols.
- Any visual implying Swiss government endorsement, legal approval, regulation, licensing, or certification.
- Any visual that hides Product Truth, chart reading, risk boundaries, or private/public separation.

## Manifest Requirement

Every Pro Max universe asset must be represented in `public/assets/promax/asset-manifest.json` with:

- asset name
- purpose
- type
- source
- license status
- original/procedural/manual status
- private internal approval status
- future public launch review requirement

## Future Public Launch Review

Private/internal approval does not equal public launch clearance. Before public use, assets must pass legal, license, brand, accessibility, performance, and Ahmad visual acceptance review.
