# Alkon Zero Truth Law

Zero Truth is a reality audit, not a deletion command.

Before Alkon acts, it reads the existing product state across the public Pro Max world, the private Founder universe, the invisible operating layer, Pro Max Trading, the workspace, Assistant, Product Truth, visual acceptance, Settings, Diagnostics, plans, apps, support, tests, reports, Git, public leak status, Station 1, and Local Day One readiness.

Zero Truth classifies each finding as accepted, ready with notes, needs visual review, needs fix, blocked, or future. It must not invent acceptance, launch readiness, billing readiness, live execution readiness, broker/feed readiness, or Local Day One completion.

If a P0 Product Truth, security, build, Git, or public leak failure exists, Alkon must choose that fix first. If no P0 exists and visual acceptance is pending, the one correct action is Ahmad visual review.

Zero Truth protects the current codebase. It forbids reset, deletion, and rebuild-from-scratch unless Ahmad explicitly approves that action.
