# Public World Completeness Matrix

Every public page must answer six questions:

1. Where am I?
2. What can I do here?
3. What is active now?
4. What is planned or future?
5. What is blocked or inactive?
6. What is the next step?

Pages:
- Home.
- Trading Workspace.
- Markets.
- Plans.
- Apps / Platforms.
- Academy.
- Community.
- Support.
- Settings.
- Diagnostics.

The matrix is implemented in `lib/server/earth-reality/public-world-matrix.ts` and surfaced through `/api/earth-reality/public-matrix`.
