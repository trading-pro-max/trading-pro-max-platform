# Solar / Weather Theme

Solar Theme uses deterministic time mapping:
- 04:30-06:00 dawn
- 06:00-08:00 sunrise
- 08:00-11:30 morning
- 11:30-16:30 day
- 16:30-18:30 golden hour
- 18:30-20:30 sunset
- 20:30-23:30 night
- 23:30-04:30 deep night

Weather Theme is manual or unavailable until a reviewed provider exists.
Supported visual states are unknown, clear, cloudy, rain, storm, snow, fog,
heat, wind, and manual.

Weather only changes atmosphere. It never claims live weather without a
configured provider, never uses GPS, and never gives trading advice.
