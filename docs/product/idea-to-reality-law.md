# Idea To Reality Law

An idea has no right to execution until it proves:

- purpose
- owner
- public/private layer
- user or project value
- risk
- tools allowed
- tools forbidden
- evidence required
- first safe step
- Ahmad decision requirement
- next fate

If any answer is missing, the idea returns to Jar or Inbox. It does not enter code, UI, routes, APIs, billing, live trading, assets, or public claims directly.
