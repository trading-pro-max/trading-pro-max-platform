# Living Earth Background System

Trading Pro Max uses a code-only Living Earth atmosphere.

Rules:

- No PNG, JPG, WebP, GIF, video, or external image assets.
- No external map assets.
- No generated images.
- Use CSS/SVG/HTML gradients, stars, orbital grid, continent hints, horizon glow, and motion only.
- Respect reduced motion.
- Keep workstation background extremely subtle and chart-safe.

Surfaces:

- Public Entry: elegant visible atmosphere.
- Workstation: subtle chart-safe layer.
- Settings and Diagnostics: light public-safe atmosphere.
- Founder Command: stronger private command atmosphere.

State behavior:

- paper_safe: stable calm motion
- fallback: slower/muted
- blocked: subtle red signal only
- review_required: segmented signal
- local_only: contained command pulse

The background is decorative and cannot track users, call external services, store location, or imply launch readiness.
