# Local Living Day Loop

The local living day loop lets Ahmad operate inside the laptop planet without launch activation.

Loop:

1. Start local day.
2. Review public world.
3. Review workstation/chart.
4. Review TPM Assistant.
5. Capture Founder ideas.
6. Classify ideas into events.
7. Generate Task Passport previews.
8. Draft Codex prompts for manual external work.
9. Wait external execution evidence.
10. Judge results through Result Tribunal.
11. Record safe Product Memory lessons.
12. Plan the next safe action.

Founder Command shows:

- today's idea intake
- open gaps
- proposed Codex drafts
- blocked requests
- visual review needs
- next safe action

Forbidden:

- public launch
- production activation
- billing
- broker/feed
- live execution
- real money
- social publishing
- shell execution from the web app
- direct Codex call from the web app
- secrets storage
