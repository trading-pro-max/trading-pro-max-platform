# Local Living Day Loop

The local living day loop lets Ahmad operate inside the laptop planet without launch activation.

Loop:

1. Start local day.
2. Review public world.
3. Review workstation/chart.
4. Review TPM Assistant.
5. Capture Founder ideas.
6. Classify ideas into events.
7. Generate Task Passport previews.
8. Draft Codex prompts for manual external work.
9. Wait external execution evidence.
10. Judge results through Result Tribunal.
11. Record safe Product Memory lessons.
12. Plan the next safe action.

Founder Command shows:

- today's idea intake
- open gaps
- proposed Codex drafts
- blocked requests
- visual review needs
- next safe action

Codebase Reality Audit readiness:

- audit needed before cleanup execution
- cleanup needed is treated as readiness, not automatic deletion
- P0 cleanup route is for build failure, public/private leaks, security/secrets risk, Product Truth violation, or chart-blocking usability
- P1 cleanup route is for important visual, navigation, support, or regression cleanup
- cleanup execution requires an explicit future task passport
- no modified or untracked files are deleted without proof they are broken duplicates and an explanation

Forbidden:

- public launch
- production activation
- billing
- broker/feed
- live execution
- real money
- social publishing
- shell execution from the web app
- direct Codex call from the web app
- secrets storage
