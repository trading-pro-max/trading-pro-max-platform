# Sovereign Task Passport

Task Passports define exactly what Codex may work on.

Required fields include task ID, event ID, mission, reason, category, risk, affected world, owner area, worker level, allowed files, forbidden files, required reviews, Product Truth requirements, public language rules, forbidden scope, validation commands, screenshot requirements, rollback rule, final report format, and expected commit message.

A passport is invalid if validation commands are missing, forbidden scope is missing, Product Truth requirements are missing, secret-like material is present, the category is critical/blocked, or public/private boundary rules are unclear.
