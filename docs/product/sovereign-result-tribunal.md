# Sovereign Result Tribunal

The Result Tribunal checks:

- tsc, eslint, build, Prisma, regression, smoke, and Git state.
- Changed files match the Task Passport.
- Forbidden files are untouched.
- Product Truth is preserved.
- No secrets or fake activation appear.
- Public/private separation is preserved.
- Screenshots exist when required.
- Ahmad visual or Founder review is requested when required.

Decisions include accepted, needs_fix, rejected, scope_violation, security_violation, product_truth_violation, public_boundary_violation, visual_review_required, founder_review_required, and blocked.
