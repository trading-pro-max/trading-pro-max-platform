# Structure Is Permission To Exist

ALKON is not organized by folder shape alone. The real structure is the right to exist.

An entity may exist only when it can answer:

1. Why does it exist?
2. Who owns it?
3. Is it public, private, invisible, tool, evidence, report, or asset?
4. Does it serve the current heart?
5. Does it create risk?
6. Does it have evidence?
7. Is it tested or does it have a documented reason?
8. What is its lifecycle?
9. What is its next fate?
10. Does it require Ahmad?

If it cannot answer, it does not go directly into code. It enters Jar or Inbox.
