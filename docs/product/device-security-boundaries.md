# Device Security Boundaries

Status: ready_with_notes

No device may bypass:

- No secrets in UI.
- No bank/card data.
- No raw biometric data storage.
- No shell execution from web app.
- No Codex execution from web app.
- No payments.
- No live execution.
- No real-money routing.
- No broker/feed activation.
- No billing activation.
- No public Alkon exposure.

Phones are review-only. Windows can build only through Ahmad's local terminal outside the web app.
