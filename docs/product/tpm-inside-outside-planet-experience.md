# TPM Inside / Outside Planet Experience

Trading Pro Max has three local worlds:

- Public Trading Platform World: users see Trading Pro Max as a professional paper-safe platform.
- Private Planet Command World: Ahmad sees Founder Command, local operations, construction readiness, memory, and safety.
- Invisible Operating Intelligence: truth, safety, memory, autonomy, diagnostics, and routing connect both worlds without leaking internal systems.

Core law:

- Ahmad lives inside the planet.
- Users live on the public trading platform surface.
- The invisible operating layer carries complexity without public leakage.

Local scope:

- No global launch.
- No production activation.
- No billing.
- No broker/feed/live execution.
- No real money.
- No social publishing.
- No shell execution from the web app.
- No generated images, raster assets, or external map assets.

Acceptance:

- Public users see Home, Trading Workspace, Markets, Plans, Apps / Platforms, Academy, Community, Support, Settings, Diagnostics, plan names, readiness, and paper-safe states only.
- Founder Command receives public/private/invisible readiness and next safe actions.
- Local-only scope is preserved.
