# Alkon Entity Doctrine

An entity is anything that exists in the product or private command system:

- page
- route
- component
- API
- feature
- plan realm
- assistant intent
- Journal/Coach item
- market surface
- support surface
- academy item
- community surface
- Alkon subsystem
- Codex task
- worker
- satellite
- station
- risk
- memory lesson
- test
- launch gate
- environment state
- visual identity element

Every entity must define purpose, served audience, owner area, owner worker, visibility, world, dependencies, outputs, boundaries, lifecycle, value, risk, validation, report target, memory, deprecation law, and removal law.
