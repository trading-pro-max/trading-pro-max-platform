# Button Reduction Law

Every button must justify why it is faster and safer than asking TPM Assistant.

Keep as buttons:
- core navigation
- sign in
- open workspace
- paper buy/sell
- AI wait
- Why Blocked when it explains the current state
- Settings and Diagnostics

Move to TPM Assistant:
- bigger chart
- make calmer
- plan explanations
- apps/platforms questions
- support guidance
- Journal/Coach help
- advanced environment controls
- Personal Reality changes
- locked feature explanations

Remove or collapse:
- repeated truth badges
- repeated sign-in controls
- repeated theme/language controls
- repeated logo actions
- repeated plan explanations
- repeated support links
