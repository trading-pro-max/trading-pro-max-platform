# Alkon Financial Legitimacy

Financial legitimacy keeps treasury decisions evidence-based and non-executing.

Checks include invoice, category, budget, reserve, founder-funded mode, revenue-funded readiness, monthly cap, ad budget, tax reserve, VAT threshold watch, accountant review, reimbursement review, and whether payment execution remains disabled from code.

Card numbers, CVV, bank credentials, payment credentials, API keys, and tokens are forbidden.
