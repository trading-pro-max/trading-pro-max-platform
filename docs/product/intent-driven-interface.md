# Intent-Driven Interface

An intent-driven interface starts with the human request, not a control catalog.

Flow:
1. User describes intent.
2. TPM Assistant classifies the request.
3. Plan access is checked.
4. Product Truth is checked.
5. Safety and privacy boundaries are checked.
6. The user receives an allowed action, explanation, safe alternative, or blocked response.

Public users see only Trading Pro Max language. Private command, Codex, task, tribunal, memory, secret, and governance terms are not public user intents.
