# Product Gap Memory

Product Gap Memory prevents known problems from being rediscovered and repeated.

Tracked gap categories:

- visual
- UX
- chart
- execution
- Assistant
- Journal/Coach
- plan clarity
- settings
- diagnostics
- Founder Command
- community
- media
- academy
- desktop/mobile
- launch-forbidden

Known protected reminders:

- avoid boxed/small UI
- reduce too many cards and borders
- keep chart dominant
- keep TPM Assistant from covering execution
- prevent internal language from leaking to normal users
- keep the Earth Mark from becoming an oversized block
- do not generate or add images unless explicitly requested

Each gap records a summary, severity, affected surface, suggested fix, owner, status, and next action. It stores product notes only, not private user data or metrics.
