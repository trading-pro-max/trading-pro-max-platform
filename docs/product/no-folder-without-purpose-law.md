# No Folder Without Purpose Law

Status: active

Every folder must have a purpose, owner layer, visibility, and next fate.

Unclear folders become cleanup_candidate, move_candidate, archive_candidate, protected, blocked, or needs_ahmad_decision. No unknown folder is moved or deleted without proof.

Permission-to-Exist amendment: a folder is not valid because it exists on disk. It must prove owner, purpose, visibility, risk, evidence, lifecycle, and next fate. Unknown folders remain Inbox / needs Ahmad review.
