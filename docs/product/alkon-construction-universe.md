# Alkon Construction Universe

Construction Universe represents Codex governance, task constitution, jurisdiction, Task Passport, execution permit, Result Tribunal, and memory lessons.

It turns private ideas and events into governed work packets.

## Allowed

- classify events
- draft Task Passports
- draft manual Codex prompts
- list allowed and forbidden files
- list validation commands
- record Result Tribunal outcomes
- create safe memory lessons

## Not Allowed

- shell execution from the web app
- direct Codex execution from the web app
- automatic external submission
- secrets in prompts
- production activation
- billing activation
- broker/feed activation
- live execution
- real-money routing
- social publishing
- fake users, revenue, or metrics
