# Global Brand Tribunal Index

The Global Brand Tribunal evaluates candidate names before adoption.

Inputs:

- candidate name
- source
- uniqueness signal
- trademark search task status
- domain search task status
- visual distinctiveness
- phonetic distinctiveness
- language safety
- sector fit
- financial/technology trust
- Swiss/global suitability without legal implication
- future-world scalability
- Ahmad fit

Outputs:

- shortlist
- needs search
- needs legal review
- reject
- black hole

No Tribunal result is a legal opinion. Ahmad approval and qualified legal review remain required.
