# Identity Memory

Identity Memory stores safe product identity preferences only. It does not store secrets, private sensitive data, credentials, social tokens, payment data, broker data, or raw user logs.

## Ahmad Preferences

- no generated images unless explicitly requested
- SVG/code identity only
- Free familiar and premium
- Pro and VIP differentiated
- Institutional public naming
- private command terms internal only
- chart-first workstation
- no clutter
- no boxed/small feeling
- Earth Mark alive but calm
- matrix Earth Mark preferred direction
- gold world-map edge preference
- no fake claims
- no competitor copying
- no noisy animation

## Persistence Rule

Identity Memory follows the product memory safety policy. It is local/internal readiness only unless a future account-safe persistence system is explicitly reviewed.
