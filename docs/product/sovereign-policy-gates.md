- Product Truth Gate
- Plan Entitlement Gate
- Public/Private Boundary Gate
- Guardian Gate
- Legal Gate
- Trust Governor Gate
- Security Sovereignty Gate
- Secrets Gate

- Founder Approval Gate

Gate decisions are `allowed`, `review_required`, `founder_approval_required`, `blocked`, or `quarantined`.
