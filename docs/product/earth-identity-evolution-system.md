# Earth Identity Evolution System

Trading Pro Max uses Earth identity layers that differ by plan and surface.

Layers:

- earthBase
- surfaceMaterial
- continentTreatment
- gridSystem
- orbitSystem
- moonBehavior
- motionLaw
- planDNA
- themeAdaptation
- stateSignal
- occasionSkin

Plan behavior:

- Free: clean realistic Earth, simple moon/orbit, low motion, no premium gold continent dominance.
- Pro: professional Earth, emerald/silver precision, more technical grid, low/medium motion.
- VIP: premium Earth, gold continent edges, gold orbit, platinum depth, stronger moon orbit, no profit promise.
- Institutional: formal Earth, navy/platinum/cyan, controlled movement, team/compliance feel.
- Founder: private command Earth, gold/graphite/Swiss red micro accent, private only.

Theme behavior:

- Light: crisp outlines, less glow, daylight clarity.
- Dark: deeper atmosphere, stronger depth, moon/orbit more visible.

Surface behavior:

- Workstation is always low-motion and chart-safe.
- Public surfaces never show Founder/private command symbols.
- Founder Command may show the strongest command atmosphere privately.
