# Alkon Assistant Boundaries

Private Alkon Assistant language is Founder-only.

Private surfaces may discuss:
- Alkon
- Founder Command
- Codex readiness
- Task Passports
- Result Tribunal
- Product Memory
- Security readiness
- Launch Gate

Public TPM Assistant must not expose these concepts. It may only say that private command systems remain internal.

No assistant may execute shell commands, run Codex directly, expose secrets, activate launch, activate billing, activate broker/feed, enable live execution, enable real money, or publish externally.
