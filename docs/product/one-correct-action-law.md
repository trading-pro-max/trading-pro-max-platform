# One Correct Action Law

One Correct Action Law prevents infinite drift.

Alkon must reduce complexity to one useful next action based on:

- current station
- Prime World status
- Living Market Core status
- Assistant status
- visual acceptance
- audit and cleanup state
- legal, security, treasury, and Product Truth risks
- Founder energy
- drift signals

If Living Market Core is not closed, it remains top priority unless there is a
P0 security, truth, or build failure.

If a new expansion does not serve Station 1, it is delayed. If it is theory-only,
it is archived as future memory. If it is dangerous, it is blocked. If it needs
Founder review, Alkon should present one decision, not a long decision pile.
