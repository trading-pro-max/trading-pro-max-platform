# World Interface Borders

## Border Law

Nothing crosses the product border automatically.

## Blocked at the Border

- Real email sending
- Social publishing
- DMs
- Account connection
- Token storage
- Spam automation
- Secret requests
- Suspicious links
- Fake partnerships
- Threats
- Brand impersonation

## Allowed at the Border

- Status-only channel readiness
- Safe classification
- Draft-only replies
- Quarantine readiness
- Evidence locker metadata without secrets
- Founder Command reporting

## Product Truth

World Interface readiness cannot activate billing, broker/feed, live execution, real-money routing, production, or social publishing.
