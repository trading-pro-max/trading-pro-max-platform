# Alkon Work Distribution System

Alkon work distribution turns private ideas, errors, risks, features, and build tasks into governed command bodies. No task is random.

Required flow:

1. Founder idea or product issue enters as a Cosmic Event.
2. The event receives Energy from Founder vision, feedback, validation, security, product truth, memory, local day, or Codex result.
3. Gravity Priority assigns P0, P1, P2, P3, blocked, or black-hole status.
4. Orbit Path routes the event to public UI, visual identity, chart workspace, Assistant, Journal/Coach, plans/realms, apps/support, security, secrets, construction, world interface, memory, local day, or forbidden launch orbit.
5. Planet/System Owner receives accountability.
6. Satellite Monitoring defines evidence.
7. Station Assignment defines operating context.
8. Worker Assignment defines allowed files/surfaces, forbidden scope, reviews, validation, report target, and memory rule.
9. Task Passport defines scope and validation.
10. Codex License decides whether a manual draft is permitted.
11. Validation checks product truth, public/private boundary, secrets, and command evidence.
12. Result Tribunal accepts, blocks, or requests fixes.
13. Memory Universe records safe lessons only.
14. Founder Command receives the report and next safe action.

Hard blocks enter the Black Hole Zone:

- live execution activation
- real-money routing
- broker/feed activation
- billing activation now
- production secrets
- social publishing automation
- sending secrets to Codex
- external offensive actions
- fake users, revenue, or metrics
- fake Sharia certification
- guaranteed profit or win-rate

Public rule:

Alkon Work Distribution is private Founder Command language. Public users see Trading Pro Max, public plan names, public surfaces, readiness, paper-safe, planned, inactive, and future states only.
