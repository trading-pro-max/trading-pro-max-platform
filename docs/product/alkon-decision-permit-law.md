# Alkon Decision Permit Law

A Decision Permit aggregates legitimacy dimensions into:

- permit_report_only
- permit_draft_only
- permit_review_required
- permit_founder_approval_required
- permit_delayed_until_ready
- permit_blocked
- permit_black_holed

Permits never execute from the web app. They are private readiness records with required reviews, rollback requirement, audit requirement, memory lesson, and next safe action.
