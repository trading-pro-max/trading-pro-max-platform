# Cross-Device Continuity

Continuity is readiness-only unless existing persistence safely supports it.

Public continuity examples:

- Web workspace to Desktop App planned.
- Academy to Mobile App planned.
- Journal note to Desktop App planned.
- Support to Mobile App planned.
- Workspace preference to Desktop App planned.

Founder continuity examples:

- Alkon Desktop Command to Alkon Pocket Universe OS planned/internal.
- Mobile idea to Desktop task graph planned.
- Tablet visual review to Memory future.
- Watch alert to Mobile decision future.

Continuity rules:

- No fake sync claim.
- No private sensitive data exposure.
- No secrets.
- No app publishing.
- No install package.
- No direct action execution.
