# Alkon Entity Death & Removal Law

Entities may be deprecated if they have unclear purpose, duplicate a stronger entity, create public/private risk, add visual clutter, lack an owner, lack validation, lack memory, create high maintenance with low value, or fail visual acceptance repeatedly.

Removal is allowed only when dependents are migrated, Product Truth is preserved, tests are updated, public/private boundaries are preserved, rollback is safe, a report is generated, and memory is archived.

Core systems are never auto-removed: Product Truth, security, Secrets Authority, plan entitlements, public/private boundaries, Alkon core, Product Memory, launch gates, treasury/tax readiness, legal/guardian systems, Codex governance, and Result Tribunal require Founder approval.
