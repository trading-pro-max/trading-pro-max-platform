# Product Memory Daily Use

Product Memory supports daily local operation by remembering safe summaries, not private data or secrets.

## Daily Memory Domains

- Founder acceptance.
- Product gaps.
- Visual feedback.
- Local day report.
- Validation summary.
- Codex build decision.
- Journal / Coach note summaries.
- Plan readiness notes.
- Assistant learning notes.

## Safe Summary Rules

Product Memory may store:

- Local day report summaries.
- Founder acceptance decisions.
- Visual feedback notes.
- Product gap notes.
- Validation command pass/fail summaries.
- Codex task outcome summaries.
- Non-sensitive product preferences.

Product Memory must not store:

- Production secrets.
- API keys.
- Passwords.
- Broker credentials.
- Payment data.
- Social tokens.
- Raw private sensitive user data.
- Raw logs with sensitive values.
- Fake users, revenue, or metrics.

## Daily Loop Integration

The daily loop creates one memory summary from:

- Latest local day state.
- Open gaps.
- Suggested next task.
- Validation status.
- Git clean expectation.
- Launch forbidden reminder.

The summary remains readiness-only and does not create surveillance, external sync, production storage, or launch automation.
