# Digital Twin Local Civilization

Local digital twins are test personas only. They are not real users and must not be counted as users, revenue, activity, or metrics.

Profiles:
- Guest visitor
- Free/Demo user
- Pro-interested user
- VIP-interested user
- Institutional future evaluator
- Arabic RTL user
- Light theme user
- New user confused by blocked states
- Founder reviewer

Each profile defines:
- journey
- visible surfaces
- expected confusion points
- pass criteria
- failure signals
- safe next actions

Rules:
- no fake users
- no private data
- no secrets
- no simulated revenue
- no launch-readiness claim from personas
