# Sovereign Owner Routing

Owner routing assigns each event to one primary owner area, supporting areas, reviews, queue, and escalation target.

Routing examples:

- Visual/UI/chart -> Design Ministry + Product + Quality.
- Logo/identity -> Visual Identity + Brand + Quality + Founder approval.
- Assistant -> Assistant + Product Truth + Guardian/Legal when risky.
- Public navigation -> Product + UX + Quality.
- Apps/platforms -> Product + Integrations + Public User World.
- Support/world interface -> World Interface + Support + Guardian/Legal.
- Secrets -> Secrets Authority + Security + Founder.
- Billing/live/broker/social/launch -> Product Truth + Security + Legal + blocked.
- Codex task -> Codex Sovereign Construction State.
- Local day -> Local Operations + Founder Command.
- Product memory -> Product Memory + Founder Command.
