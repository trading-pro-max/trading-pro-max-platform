# No Route Without Purpose Law

Status: active

Routes are product contracts.

## Canonical Public Routes

- `/` = Pro Max Center
- `/trading` = Pro Max Trading / Trading Workspace
- `/markets` = Markets if promoted as a route in a future pass
- `/plans` = Plans if promoted as a route in a future pass
- `/apps` = Apps / Platforms if promoted as a route in a future pass
- `/support` = Support if promoted as a route in a future pass
- `/diagnostics` = public-safe Diagnostics
- `/settings` = public-safe Settings

## Private Routes

- `/founder/alkon` = Alkon private command universe
- `/founder/pocket` = Alkon Pocket private decision center

## Compatibility Routes

`/en` may remain route-compatible, but it is not the primary Pro Max Trading identity.

## Forbidden Route Behavior

- Public navigation must not link Founder routes.
- Founder routes must not use public navigation.
- Public pages must not render Alkon private language.
- No route may activate live trading, real money, billing, broker/feed, production launch, shell, Codex, email, external accounts, or publishing.
