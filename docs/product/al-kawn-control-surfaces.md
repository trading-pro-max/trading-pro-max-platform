# Al-Kawn Control Surfaces

## Definition

Control surfaces are private command panels for every core layer of الكون.

They make the system controllable, not only visible. Each surface must show:

- current state
- owner layer
- visible state
- direct internal actions
- legal stop actions
- money stop actions
- blocked actions
- Product Truth impact
- next safe action

## Why Control Surfaces Come Before Infinity / Operator

Infinity Mode and Operator Mode remain future-gated. Control surfaces come first because each layer needs a clear execution law before future automation can be prepared.

Required action law:

- داخل الكون: التنفيذ مباشر.
- عند القانون: يتوقف لأحمد.
- عند المال: يتوقف لأحمد.
- Product Truth هو قانون الحقيقة الأعلى.
- Universe Operating Kernel هو القاضي التنفيذي.

## Action Classification

Every action is classified as one of:

- `execute_directly`
- `stop_for_legal`
- `stop_for_money`
- `blocked_product_truth`
- `blocked_security`
- `future_gate`
- `needs_more_evidence`

Direct internal actions can run inside الكون only when they are private, safe, non-secret, and Product Truth preserving.

Legal, money, broker, payment, public launch, brand, domain, external account, and final decision actions stop for Ahmad.

Product Truth violations and secret/public exposure are blocked.

## Desktop Integration

`/desktop/kawn` is the main private command client for الكون and the primary UI for the Control Surfaces grid and selected detail panel.

## Founder Universe Integration

`/founder/universe` shows a compact Al-Kawn Control Surfaces summary with counts, next safe action, and a link to `/desktop/kawn`.

## Trading Integration

`/trading` remains chart-first and compact. It may show only a tiny Earth Control status chip, while Product Truth stays visible.

## Product Truth Priority

Control surfaces do not activate:

- Infinity Mode
- Operator Mode
- public launch
- billing
- payments
- receiving money
- real money
- broker execution
- legal approval
- FINMA approval
- public الكون
- public ALKON

Control surfaces prepare safer future work; they do not execute future-gated work.
