# Global Brand Search Tasks

Status: manual_tasks_ready

For each candidate, Ahmad or a qualified reviewer must complete:

- WIPO Global Brand Database exact, visual, and phonetic search
- USPTO trademark search
- EUIPO / TMview search
- Swiss IPI / Swissreg search if Swiss-facing use is planned
- `.com` domain check
- `.ai` domain check
- `.app` domain check
- `.ch` domain check
- future social handle check without account creation
- phonetic similarity review
- language safety review for Arabic, English, German, French, Italian, and Spanish
- qualified legal review

Boundary:

The app generated tasks only. No external calls, scraping, domain purchase, trademark filing, payment, or legal claim was made.
